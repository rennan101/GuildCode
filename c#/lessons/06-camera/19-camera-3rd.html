19. Camera 3ª Pessoa (Cinemachine)

Módulo 6 — Câmeras

Uma camera de 3ª pessoa mostra o personagem de tras. O Cinemachine e a ferramenta oficial do Unity para cameras inteligentes.

19.1 — Configurando Cinemachine

Passo a passo no Editor:
1. Instale Cinemachine: Window → Package Manager → Unity Registry → Cinemachine → Install
2. Selecione a Main Camera no Hierarchy
3. Menu: Cinemachine → Create Virtual Camera
4. Selecione a VirtualCamera criada
5. No Inspector, em "Follow", arraste o Player (Capsule)
6. Em "Look At", arraste o Player tambem
7. Ajuste: Body → Y Damping = 2, X Damping = 3, Z Damping = 5
8. Ajuste: Aim → Horizontal/Vertical Damping = 2

19.2 — Camera Follow via Script

using UnityEngine;

public class CameraTerceiraPessoa : MonoBehaviour
{
    [SerializeField] private Transform alvo;
    [SerializeField] private Vector3 offset = new Vector3(0, 5, -8);
    [SerializeField] private float suavidade = 5f;

    private float rotacaoY;

    void LateUpdate()
    {
        if (alvo == null) return;

        // Seguir o player com offset
        rotacaoY = alvo.eulerAngles.y;
        Quaternion rotacao = Quaternion.Euler(0, rotacaoY, 0);

        Vector3 posicaoAlvo = alvo.position + rotacao * offset;

        transform.position = Vector3.Lerp(
            transform.position,
            posicaoAlvo,
            suavidade * Time.deltaTime
        );

        transform.LookAt(alvo.position + Vector3.up * 1.5f);
    }
}
Passo a passo no Editor:
1. Crie um Player (Capsule) com movimento WASD
2. Selecione a Main Camera
3. Adicione o script CameraTerceiraPessoa
4. No Inspector, arraste o Player para o campo "Alvo"
5. Clique em Play e mova o Player
6. A camera segue suavemente por tras!
Dica do Professor: Cinemachine e mais poderoso que script manual: resolve colisoes com paredes, suaviza movimentos, e funciona com multiples cameras. Para projetos reais, use Cinemachine!
Atividade Pratica no Unity:
1. Instale Cinemachine e crie uma Virtual Camera
2. Configure Follow e Look At para o Player
3. Teste o movimento com WASD + mouse
4. Ajuste damping para camera mais suave ou mais responsiva
5. Compare com uma camera follow manual (script)

26. Audio 3D

Módulo 8 — Interface e Sistemas

Sons dao vida ao jogo. O Unity suporta audio 2D (musica, UI) e audio 3D (sons espaciais que mudam com a posicao).

26.1 — Componentes de Audio

ComponenteFuncao
Audio SourceEmite o som (como um "alto-falante" no mundo)
Audio ListenerOuve o som (geralmente na Camera principal)
Audio ClipO arquivo de audio (.wav, .mp3, .ogg)
Passo a passo no Editor:
1. Importe um audio: arraste um arquivo .wav ou .mp3 para Assets/Audio
2. Selecione um GameObject (ex: inimigo)
3. Adicione componente: Audio Source
4. No Inspector, arraste o AudioClip para o campo "AudioClip"
5. Marque "Play On Awake" para tocar ao iniciar
6. Ajuste: Volume, Spatial Blend (0=2D, 1=3D), Min/Max Distance

26.2 — Audio via Script

using UnityEngine;

public class AudioJogador : MonoBehaviour
{
    [SerializeField] private AudioClip somPulo;
    [SerializeField] private AudioClip somDano;
    [SerializeField] private AudioClip somMoeda;

    private AudioSource audioSource;

    void Start()
    {
        audioSource = GetComponent<AudioSource>();
    }

    public void TocarPulo()
    {
        audioSource.PlayOneShot(somPulo); // Nao interrompe outros sons
    }

    public void TocarDano()
    {
        audioSource.PlayOneShot(somDano);
    }

    public void TocarMoeda()
    {
        audioSource.PlayOneShot(somMoeda);
    }

    // Audio 3D: o som vem de um objeto no mundo
    public void TocarExplosaoEm(Vector3 posicao)
    {
        AudioSource.PlayClipAtPoint(somDano, posicao);
    }
}

26.3 — Audio 3D vs 2D

Audio 2D (Spatial Blend = 0): Volume constante, nao importa posicao. Para: musica de fundo, sons de UI.

Audio 3D (Spatial Blend = 1): Volume diminui com distancia. Para: passos, tiros, conversas de NPCs, efeitos ambientais.
Atividade Pratica no Unity:
1. Crie um GameObject com Audio Source (som de fogo 3D)
2. Implemente: ao pular, toca som de pulo (2D)
3. Implemente: ao coletar moeda, toca som de moeda (2D)
4. Crie uma tocha com Audio Source 3D (Range: 10)
5. Aproxime e afaste da tocha — o som deve ficar mais alto/mais baixo
Resultado esperado:
• Som de pulo toca ao pressionar Espaco
• Som de moeda toca ao coletar
• Som de tocha diminui ao afastar

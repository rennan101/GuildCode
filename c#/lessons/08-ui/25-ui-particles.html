25. Sistemas de Particulas (VFX Graph)

Módulo 8 — Interface e Sistemas

Sistemas de particulas criam efeitos visuais como fogo, agua, fumaca, explosoes, magia, etc.

25.1 — Particle System Basico

Passo a passo no Editor:
1. Menu: GameObject → Effects → Particle System
2. Selecione o Particle System no Hierarchy
3. No Inspector, veja as configuracoes:
   • Duration: 5 (duracao do ciclo)
   • Looping: true (repetir infinitamente)
   • Start Lifetime: 2 (quanto tempo cada particula vive)
   • Start Speed: 5 (velocidade inicial)
   • Start Size: 0.5 (tamanho)
   • Start Color: branco (cor)
   • Gravity Modifier: 1 (gravidade nas particulas)
4. Ajuste Start Color para laranja e teste!

25.3 — Controle via Script

using UnityEngine;

public class ControleParticulas : MonoBehaviour
{
    [SerializeField] private ParticleSystem particulasFogo;
    [SerializeField] private ParticleSystem explosao;

    void Update()
    {
        // Play/Stop
        if (Input.GetKeyDown(KeyCode.F))
        {
            if (particulasFogo.isPlaying)
                particulasFogo.Stop();
            else
                particulasFogo.Play();
        }

        // Explosao unica
        if (Input.GetKeyDown(KeyCode.E))
        {
            explosao.Play();
        }

        // Alterar propriedades em tempo real
        var main = particulasFogo.main;
        main.startColor = Color.red;
        main.startSpeed = 10f;
    }
}
Atividade Pratica no Unity:
1. Crie um efeito de fogo: Start Color laranja, Shape cone, Gravity 1
2. Crie um efeito de explosao: Shape sphere, Start Lifetime 0.5, Start Speed 20
3. Implemente: F liga/desliga fogo, E dispara explosao
4. Crie particulas de chuva: Shape box (largo), Start Speed alto, gravidade
Resultado esperado:
• Fogo aparece/desaparece com F
• Explosao acontece com E
• Chuva cai continuamente

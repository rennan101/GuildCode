22. Terreno e Paisagem

Módulo 7 — Mundo 3D

O sistema de Terrain do Unity permite criar paisagens 3D com relevos, texturas, vegetacao e agua.

22.1 — Criando um Terreno

Passo a passo no Editor:
1. Menu: GameObject → 3D Object → Terrain
2. Selecione o Terrain no Hierarchy
3. No Inspector, veja a barra de ferramentas do Terrain
4. Clique no botao de "pincel" (Paint Height)
5. Ajuste: Brush Size (tamanho do pincel), Opacity (intensidade)
6. Clique e arraste no Scene View para elevar o terreno

22.2 — Ferramentas do Terrain

FerramentaFuncao
Raise/LowerElevar/rebaixar o relevo
Paint HeightDefinir altura especifica
SmoothSuavizar bordas
Paint TextureAplicar texturas (grama, terra, pedra)
Paint TreesPlantar arvores
Paint DetailsAdicionar grama e detalhes

22.3 — Configuracoes do Terrain

using UnityEngine;

public class ConfigurarTerreno : MonoBehaviour
{
    void Start()
    {
        Terrain terreno = GetComponent<Terrain>();
        TerrainData dados = terreno.terrainData;

        // Tamanho do terreno
        Debug.Log($"Tamanho: {dados.size}");

        // Resolucao
        Debug.Log($"Altura: {dados.heightmapResolution}");
        Debug.Log($"Alfama: {dados.alphamapResolution}");
    }
}

22.4 — Terreno Dinamico via Script

using UnityEngine;

public class TerrenoDinamico : MonoBehaviour
{
    [SerializeField] private float raioEfeito = 5f;
    [SerializeField] private float intensidade = 0.1f;

    void Update()
    {
        if (Input.GetMouseButton(0))
        {
            Ray raio = Camera.main.ScreenPointToRay(Input.mousePosition);

            if (Physics.Raycast(raio, out RaycastHit hit))
            {
                Terrain terreno = Terrain.activeTerrain;
                Vector3 posTerreno = terreno.transform.position;
                Vector3 posLocal = hit.point - posTerreno;

                float[,] alturas = terreno.terrainData.GetHeights(
                    (int)(posLocal.x / terreno.terrainData.size.x * terreno.terrainData.heightmapResolution),
                    (int)(posLocal.z / terreno.terrainData.size.z * terreno.terrainData.heightmapResolution),
                    1, 1
                );

                alturas[0, 0] += intensidade * Time.deltaTime;
                terreno.terrainData.SetHeights(
                    (int)(posLocal.x / terreno.terrainData.size.x * terreno.terrainData.heightmapResolution),
                    (int)(posLocal.z / terreno.terrainData.size.z * terreno.terrainData.heightmapResolution),
                    alturas
                );
            }
        }
    }
}
Atividade Pratica no Unity:
1. Crie um Terreno e esculpa um morro com a ferramenta Raise
2. Aplique 3 texturas: gram, terra, pedra (precisa de texturas .png)
3. Plante 10 arvores com Paint Trees
4. Adicione 50 detalhes de grama com Paint Details
5. Implemente elevacao dinamica com clique do mouse
Resultado esperado:
• Terreno com morros e vales
• Texturas diferentes em areas diferentes
• Arvores e grama distribuidas
• Clique do mouse eleva o terreno em tempo real

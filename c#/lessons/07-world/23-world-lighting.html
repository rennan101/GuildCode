23. Iluminacao

Módulo 7 — Mundo 3D

Iluminacao define a atmosfera do jogo. O Unity 6.5 usa o URP com Adaptive Probe Volumes (APV) para iluminacao global automatica.

23.1 — Tipos de Luz

TipoDescricaoUso TipicoCusto
DirectionalLuz paralela infinitaSol, LuaBaixo
PointEmite de um ponto (esfera)Lampada, tochaMedio
SpotCone de luz direcionalRefletor, farolMedio
AreaSuperficie retangular/circularPorta, janelaAlto
Passo a passo — Adicionando Luzes:
1. Menu: GameObject → Light → Directional Light (ja existe na cena)
2. Selecione a Directional Light → Inspector
3. Ajuste: Color (cor do sol), Intensity (1.2 recomendado), Shadows (Soft)
4. Menu: GameObject → Light → Point Light
5. Posicione a Point Light perto de um objeto
6. Ajuste: Range (alcance), Color, Intensity

23.2 — Configuracao via Codigo

using UnityEngine;
using UnityEngine.Rendering.Universal;

public class ConfigurarLuz : MonoBehaviour
{
    [SerializeField] private Light luzPrincipal;

    void Start()
    {
        // Configurar luz direcional (sol)
        luzPrincipal.type = LightType.Directional;
        luzPrincipal.color = new Color(1f, 0.95f, 0.8f); // Sol quente
        luzPrincipal.intensity = 1.2f;

        // Sombras
        luzPrincipal.shadows = LightShadows.Soft;
        luzPrincipal.shadowStrength = 0.8f;

        // Em tempo real, mudar angulo do sol
        luzPrincipal.transform.rotation = Quaternion.Euler(50f, -30f, 0f);
    }
}

23.3 — Lightmapping (Bake)

Passo a passo — Bake de Iluminacao:
1. Marque objetos estaticos como "Static" (checkbox no Inspector)
2. Window → Rendering → Lighting
3. Configure Lightmapping Settings:
   • Lightmapper: Progressive GPU (mais rapido)
   • Lightmap Resolution: 20-40 texels/unidade
   • Compress: Sim (economiza memoria)
4. Clique "Generate Lighting"
5. Aguarde o processo (pode demorar)
6. Compare: antes e depois do bake — sombras reais!

23.4 — Post-Processing

// Post-Processing via Volume Profile:
// - Bloom: brilho de luzes intensas
// - Color Grading: correcao de cor / look visual
// - Ambient Occlusion: sombras de canto
// - Vignette: escurecimento nas bordas
// - Motion Blur: desfoque de movimento
// - Depth of Field: desfoque de profundidade
Passo a passo — Post-Processing:
1. GameObject → Volume → Global Volume
2. Selecione o Volume → Inspector → Add Override
3. Adicione: Bloom, Color Grading, Vignette
4. Ajuste cada efeito ate ficar com a aparencia desejada
Atividade Pratica no Unity:
1. Crie uma cena: 3 Cubes, 1 plano (chao), 1 Directional Light
2. Adicione 2 Point Lights com cores diferentes
3. Configure sombras soft na luz principal
4. Faca bake de iluminacao e compare com e sem bake
5. Adicione um Volume Global com Bloom e Color Grading
Resultado esperado:
• Cena iluminada com sombras suaves
• Point lights com cores diferentes (vermelho e azul)
• Objetos estaticos com sombras baked (mais realistas)
• Post-processing com bloom (brilho) e vignette (bordas escuras)

DESAFIO DO MODULO 7 — Cena Iluminada

Crie uma cena com iluminacao profissional!

Requisitos:
1. Monte uma sala com 4 paredes e 1 chao
2. Adicione 1 Point Light como "lampada" no teto
3. Adicione 1 Spot Light como "refletor" na parede
4. Faca bake de iluminacao
5. Adicione Post-Processing: Bloom (fraco), Color Grading (temperatura quente), Vignette ( leve)
6. Adicione 1 model 3D importado (pode ser um asset gratuito)
Resultado esperado:
• Sala iluminada com lampada e refletor
• Sombras realistas nos cantos
• Post-processing dando look cinematografico
• Modelo 3D posicionado na sala

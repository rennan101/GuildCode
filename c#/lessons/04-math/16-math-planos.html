16. Raycasting e Planos 3D

Módulo 4 — Matemática 3D

Raycasting e como voce "dispara um raio" no mundo 3D para detectar objetos. E usado para mira, deteccao de chao, clique do mouse no mundo, etc.

16.1 — Raycast Basico

using UnityEngine;

public class DeteccaoRaycast : MonoBehaviour
{
    [SerializeField] private float distanciaRaio = 50f;

    void Update()
    {
        // Raio que vai da posicao deste objeto para frente
        if (Physics.Raycast(transform.position, transform.forward, out RaycastHit hit, distanciaRaio))
        {
            Debug.Log($"Acertou: {hit.collider.name}");
            Debug.Log($"Distancia: {hit.distance}");
            Debug.Log($"Ponto de impacto: {hit.point}");
            Debug.Log($"Normal da superficie: {hit.normal}");
        }
    }

    // Visualizar o raio no Scene View
    void OnDrawGizmos()
    {
        Gizmos.color = Color.red;
        Gizmos.DrawRay(transform.position, transform.forward * distanciaRaio);
    }
}
Passo a passo no Editor:
1. Crie 3 Cubos espalhados na cena
2. Crie um GameObject vazio na posicao (0, 1, 0)
3. Adicione o script DeteccaoRaycast
4. No Scene View, veja o raio vermelho apontando para frente
5. Mova o objeto e alinhe com um Cube
6. Clique em Play e veja no Console
Saida esperada (quando o raio atinge um Cube):
Acertou: Cube
Distancia: 3.5
Ponto de impacto: (0.0, 1.0, 3.5)
Normal da superficie: (0.0, 0.0, -1.0)

16.2 — Raycast do Mouse (Clicar no Mundo)

void Update()
{
    if (Input.GetMouseButtonDown(0))
    {
        // Cria raio da camera ate onde o mouse clicou
        Ray raio = Camera.main.ScreenPointToRay(Input.mousePosition);

        if (Physics.Raycast(raio, out RaycastHit hit))
        {
            Debug.Log($"Clicou em: {hit.collider.name}");
            Debug.Log($"Posicao no mundo: {hit.point}");
        }
    }
}
Passo a passo no Editor:
1. Adicione este codigo a um script na Camera
2. Crie varios Cubos na cena
3. Clique em Play
4. Clique com o mouse em cima dos Cubos
5. Veja no Console qual objeto foi clicado e em que posicao

16.3 — SphereCast e BoxCast

// SphereCast: raio "gordo" (esfera ao longo do raio)
// Util para detectar com margem de erro
if (Physics.SphereCast(transform.position, 0.5f, transform.forward, out RaycastHit hit, 10f))
{
    Debug.Log($"SphereCast acertou: {hit.collider.name}");
}

// BoxCast: raio em forma de caixa
if (Physics.BoxCast(transform.position, Vector3.one * 0.5f, transform.forward, out RaycastHit hit2, transform.rotation, 10f))
{
    Debug.Log($"BoxCast acertou: {hit2.collider.name}");
}
Tipos de Raycast:
• Raycast — linha fina (ponto exato)
• SphereCast — raio com raio (detecta com margem)
• BoxCast — raio em forma de caixa
• RaycastAll — acerta TODOS os objetos no caminho
• RaycastNonAlloc — sem alocacao de memoria (melhor performance)

16.4 — Projecao Perspectiva vs Ortogonal

Camera Perspective: Objetos distantes parecem menores. Usada em jogos 3D, FPS, TPS.
Camera Orthographic: Objetos mantem tamanho independente da distancia. Usada em jogos 2D, isometricos.
Passo a passo — Testando Camera:
1. Selecione a Main Camera no Hierarchy
2. No Inspector, veja "Projection" (Perspective ou Orthographic)
3. Mude para Orthographic e ajuste Size
4. Veja a diferenca no Scene View
Atividade Pratica no Unity:
1. Implemente um raycast que detecta o chao abaixo do player
2. Crie um "ground check" usando Physics.Raycast apontando para baixo
3. Implemente clique do mouse para mover um Cube ate o ponto clicado
4. Teste com Camera Perspective e Orthographic
Saida esperada:
No chao: true
Clicou em: Chao | Posicao: (3.5, 0.0, 7.2)

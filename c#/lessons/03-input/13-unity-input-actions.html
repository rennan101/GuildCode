13. Input Actions Completo

Módulo 3 — Input System

Nesta aula vamos criar um sistema de input completo usando Input Actions, incluindo movimento, pulo, correr e interacao.

13.1 — Configurando o Asset InputActions

Passo a passo — Criando o Asset:
1. Na pasta Assets, clique com botao direito → Create → Input Actions
2. Nomeie "PlayerControls"
3. Abra o asset (duplo clique)
4. Crie um Action Map chamado "Player"
5. Adicione as seguintes Actions:
ActionTypeBinding
MoveValue — Vector2WASD (composite)
LookValue — Vector2Mouse Delta
JumpButtonSpace
SprintButtonLeft Shift
InteractButtonE

13.2 — Script Completo com Input Actions

using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody))]
public class PlayerController : MonoBehaviour
{
    [Header("Movimento")]
    [SerializeField] private float velocidadeWalk = 6f;
    [SerializeField] private float velocidadeRun = 10f;
    [SerializeField] private float forcaPulo = 12f;

    [Header("Ground Check")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float raioCheck = 0.3f;
    [SerializeField] private LayerMask chaoMask;

    private Rigidbody rb;
    private Vector2 inputMovimento;
    private Vector2 inputOlhar;
    private bool pulando;
    private bool correndo;
    private bool noChao;
    private float rotacaoX;

    void Start()
    {
        rb = GetComponent<Rigidbody>();
        rb.freezeRotation = true;
        rb.interpolation = RigidbodyInterpolation.Interpolate;
    }

    // Metodos chamados pelo Player Input component
    public void OnMove(InputAction.CallbackContext context)
    {
        inputMovimento = context.ReadValue<Vector2>();
    }

    public void OnLook(InputAction.CallbackContext context)
    {
        inputOlhar = context.ReadValue<Vector2>();
    }

    public void OnJump(InputAction.CallbackContext context)
    {
        if (context.performed && noChao)
        {
            rb.AddForce(Vector3.up * forcaPulo, ForceMode.Impulse);
            Debug.Log("Pulou!");
        }
    }

    public void OnSprint(InputAction.CallbackContext context)
    {
        correndo = context.performed;
    }

    public void OnInteract(InputAction.CallbackContext context)
    {
        if (context.performed)
        {
            Debug.Log("Interagiu!");
        }
    }

    void FixedUpdate()
    {
        // Verificar chao
        noChao = Physics.CheckSphere(groundCheck.position, raioCheck, chaoMask);

        // Movimento
        float velocidade = correndo ? velocidadeRun : velocidadeWalk;
        Vector3 move = new Vector3(inputMovimento.x, 0, inputMovimento.y);
        rb.linearVelocity = new Vector3(
            move.x * velocidade,
            rb.linearVelocity.y,
            move.z * velocidade
        );
    }

    void Update()
    {
        // Olhar (rotacao)
        float mouseX = inputOlhar.x * Time.deltaTime * 100f;
        float mouseY = inputOlhar.y * Time.deltaTime * 100f;

        rotacaoX -= mouseY;
        rotacaoX = Mathf.Clamp(rotacaoX, -90f, 90f);

        transform.Rotate(Vector3.up, mouseX);

        if (Camera.main != null)
        {
            Camera.main.transform.localRotation = Quaternion.Euler(rotacaoX, 0, 0);
        }
    }
}
Passo a passo no Editor:
1. Crie um Capsule nomeado "Player"
2. Adicione Rigidbody e o script PlayerController
3. Crie um GameObject vazio como filho do Player, nomeie "GroundCheck" e posicione em Y=-1
4. Arraste GroundCheck para o campo no Inspector
5. Crie um Layer "Chao" e aplique ao chao da cena
6. Selecione Player → Player Input component → Actions = PlayerControls
7. Behavior = Invoke Unity Events
8. Configure os eventos: OnMove, OnLook, OnJump, OnSprint, OnInteract

13.3 — Player Input via Events (Alternativa)

// Alternativa: usar PlayerInput component com events
// No Inspector do Player:
// 1. Player Input → Behavior: Invoke Unity Events
// 2. Na secao Events, conecte cada acao ao metodo correspondente:
//    - OnMove → PlayerController.OnMove
//    - OnJump → PlayerController.OnJump
//    etc.
Dica do Professor: O metodo OnMove (ou qualquer metodo de callback) DEVE ter exatamente o mesmo nome da Action no Input Actions asset. Se voce renomear a Action, renomeie o metodo tambem!
Atividade Pratica no Unity:
1. Crie o asset PlayerControls com todas as Actions da tabela
2. Implemente o script PlayerController completo
3. Teste: movimentacao WASD, pulo com Espaco, corrida com Shift
4. Observe a diferenca de velocidade entre caminhar e correr
5. Teste a interacao com E (pode ser apenas Debug.Log por enquanto)
Saida esperada:
• Ao pressionar Espaco: Pulou!
• Ao segurar Shift + W: movimento mais rapido
• Ao pressionar E: Interagiu!

DESAFIO DO MODULO 3 — Controles Customizados

Crie um sistema de input personalizado para um jogo de top-down!

Requisitos:
1. Crie um PlayerInput asset com: Move (WASD), Shoot (Left Click), Dash (Space), Pause (Escape)
2. Implemente movimentacao top-down (movimento no plano XZ, sem gravidade)
   • Use Keyboard.current[Key.W].isPressed para movimento simples
3. Implemente Dash: ao pressionar Space, o player se move instantaneamente na direcao que esta andando
4. Implemente tiro: ao clicar, crie um projetil (Instantiate) que se move na direcao do mouse
5. Implemente pause: ao pressionar Escape, pause o jogo (Time.timeScale = 0) e mostre "PAUSADO"
Resultado esperado:
• WASD move o player no plano
• Espaco faz um dash rapido na direcao atual
• Clique esquerdo dispara projetil
• Escape pausa/despausa o jogo

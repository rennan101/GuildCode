18. Colisoes e Triggers

Módulo 5 — Física 3D

Colisoes detectam quando dois objetos se tocam. Triggers detectam quando um objeto entra numa area sem bloquear o movimento.

18.1 — Colisao vs Trigger

ColisaoTrigger
Collider com "Is Trigger" desmarcadoCollider com "Is Trigger" marcado
Bloqueia o movimentoNao bloqueia (objeto passa por cima)
OnCollisionEnterOnTriggerEnter
Usado para: chao, paredes, obstaculosUsado para: areas de coleta, zonas de dano
Passo a passo — Configurando Trigger:
1. Crie um Sphere (player) e um Cube (inimigo)
2. Ambos precisam de Collider
3. No Cube, marque "Is Trigger" no BoxCollider
4. Ao clicar Play e encostar no Cube, o player passa por ele

18.2 — Deteccao de Colisoes

using UnityEngine;

public class DeteccaoColisao : MonoBehaviour
{
    // Quando COMECA a colidir
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log($"Colidiu com: {collision.gameObject.name}");
        Debug.Log($"Forca do impacto: {collision.relativeVelocity.magnitude}");

        // Acessar ponto de contato
        foreach (ContactPoint contato in collision.contacts)
        {
            Debug.Log($"Ponto de contato: {contactPoint.point}");
        }
    }

    // Enquanto ESTA colidindo
    void OnCollisionStay(Collision collision)
    {
        // Chamado a cada frame enquanto encostando
    }

    // Quando PARA de colidir
    void OnCollisionExit(Collision collision)
    {
        Debug.Log($"Saiu de colisao com: {collision.gameObject.name}");
    }
}

18.3 — Deteccao de Triggers

void OnTriggerEnter(Collider other)
{
    Debug.Log($"Entrou na zona: {other.gameObject.name}");

    // Exemplo: pegar moeda
    if (other.CompareTag("Moeda"))
    {
        Destroy(other.gameObject);
        Debug.Log("Pegou uma moeda!");
    }

    // Exemplo: zona de dano
    if (other.CompareTag("ZonaDano"))
    {
        Debug.Log("Está em zona de dano!");
    }
}

void OnTriggerExit(Collider other)
{
    Debug.Log($"Saiu da zona: {other.gameObject.name}");
}
Passo a passo no Editor:
1. Crie um Plane como chao
2. Crie 3 Spheres como "Moedas" com tag "Moeda" e Is Trigger marcado
3. Crie um Capsule como Player com Rigidbody e Collider
4. Adicione o script de deteccao ao Player
5. Clique em Play e mova o Player ate as Moedas
6. As Moedas desaparecem ao serem tocadas
Saida esperada:
Entrou na zona: Moeda_1
Pegou uma moeda!
Entrou na zona: Moeda_2
Pegou uma moeda!
Dica do Professor: Use CompareTag("nome") em vez de gameObject.name == "nome". Tags sao mais rapidas e evitam erros de digitacao!
Atividade Pratica no Unity:
1. Crie uma pista com 5 moedas (Sphere + Trigger + tag "Moeda")
2. Crie uma zona de dano (Cube vermelho + Trigger + tag "ZonaDano")
3. Implemente: moeda = +10 pontos, zona de dano = -1 vida
4. Exiba pontuacao e vida no Console
Saida esperada:
Pegou moeda! Pontos: 10
Pegou moeda! Pontos: 20
Em zona de dano! Vida: 90

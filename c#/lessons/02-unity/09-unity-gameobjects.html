9. GameObjects e Components

Módulo 2 — Fundamentos do Unity

Tudo no Unity e um GameObject. Uma camera, um cubo, uma luz, um player — tudo sao GameObjects. E cada GameObject e feito de Components (componentes).

9.1 — A Composicao do Unity

Um GameObject vazio e apenas um ponto no espaco. Os Components e que definem o que ele faz e como ele parece:

// Um GameObject tipico tem:
// ┌─────────────────────────────┐
// │  GameObject: "Player"       │
// │  ├─ Transform (obrigatorio) │ ← posicao, rotacao, escala
// │  ├─ MeshRenderer            │ ← aparencia visual
// │  ├─ MeshFilter              │ ← geometria 3D
// │  ├─ Rigidbody               │ ← fisica
// │  ├─ BoxCollider             │ ← colisao
// │  └─ PlayerController (seu!) │ ← comportamento
// └─────────────────────────────┘
Passo a passo no Editor:
1. Crie um Cube na cena (GameObject → 3D Object → Cube)
2. Selecione o Cube e veja no Inspector: Transform, MeshFilter, MeshRenderer, BoxCollider
3. Adicione um componente: Component → Physics → Rigidbody
4. Agora o Cube tem 5 componentes!

9.2 — Acessando Components pelo Codigo

using UnityEngine;

public class ExplorarComponents : MonoBehaviour
{
    void Start()
    {
        // GetComponent — encontra um componente neste GameObject
        Rigidbody rb = GetComponent<Rigidbody>();
        Collider col = GetComponent<Collider>();

        // Se o componente nao existir, retorna null
        if (rb != null)
        {
            Debug.Log($"Rigidbody encontrado! Massa: {rb.mass}");
        }

        // GetComponentInChildren — busca neste e em filhos
        Renderer rend = GetComponentInChildren<Renderer>();

        // Acessar outro GameObject pela cena
        GameObject inimigo = GameObject.Find("Orc");
        if (inimigo != null)
        {
            Debug.Log($"Inimigo encontrado: {inimigo.name}");
        }

        // Acessar por Tag (mais performatico que Find)
        GameObject jogador = GameObject.FindWithTag("Player");
    }
}
Passo a passo no Editor:
1. Crie um Cube e nomeie "Orc"
2. Adicione um script ExplorarComponents a ele
3. Adicione um Rigidbody ao Orc (Component → Physics → Rigidbody)
4. Clique em Play e veja o Console
Saida esperada no Console:
Rigidbody encontrado! Massa: 1

9.3 — Tags e Layers

void OnCollisionEnter(Collision collision)
{
    // Comparar tag do objeto que colidiu
    if (collision.gameObject.CompareTag("Inimigo"))
    {
        Debug.Log("Colidiu com um inimigo!");
    }
    if (collision.gameObject.CompareTag("Moeda"))
    {
        Debug.Log("Pegou uma moeda!");
    }
}
Passo a passo no Editor — Configurando Tags:
1. Selecione o GameObject "Orc" no Hierarchy
2. No Inspector, clique no dropdown "Tag" (no topo)
3. Selecione "Inimigo" (ou crie uma nova tag em Edit → Project Settings → Tags and Layers)
4. Repita para outros GameObjects com tags diferentes

9.4 — Criando e Destruindo GameObjects

public class GerenciadorDeInimigos : MonoBehaviour
{
    [SerializeField] private GameObject inimigoPrefab;
    [SerializeField] private int maxInimigos = 5;

    private List<GameObject> inimigosAtivos = new List<GameObject>();

    void Start()
    {
        // Criar inimigos
        for (int i = 0; i < maxInimigos; i++)
        {
            Vector3 pos = new Vector3(i * 3, 0, 5);
            GameObject novoInimigo = Instantiate(inimigoPrefab, pos, Quaternion.identity);
            novoInimigo.name = $"Inimigo_{i}";
            inimigosAtivos.Add(novoInimigo);
        }
    }

    void DestruirTodos()
    {
        foreach (GameObject inimigo in inimigosAtivos)
        {
            if (inimigo != null)
                Destroy(inimigo);
        }
        inimigosAtivos.Clear();
    }
}
Dica do Professor: Evite GameObject.Find() dentro de Update() — e lento! Use referencias diretas via [SerializeField] no Inspector, ou busque uma unica vez no Start().
Atividade Pratica no Unity:
1. Crie 3 GameObjects: um Cube (tag "Inimigo"), uma Sphere (tag "Moeda"), um Capsule (tag "Player")
2. Crie um script que use FindWithTag para localizar cada um
3. Use GetComponent para obter o Renderer de cada um e mudar a cor
4. Teste com Instantiate() para criar clones de um prefab
Saida esperada no Console:
Inimigo encontrado: Orc
Cor do Inimigo alterada para vermelho
Cor da Moeda alterada para amarelo
Clones criados: 5

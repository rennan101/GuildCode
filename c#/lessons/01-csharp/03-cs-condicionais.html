3. Condicionais — Tomando Decisões

Módulo 1 — Fundamentos de C# para Unity

Condicionais permitem que o programa tome decisões. É assim que o jogo sabe se o jogador morreu, se pode atacar, se pegou um item, etc.

3.1 — If / Else / Else If

O if verifica uma condição: se for true, executa o código dentro das chaves. Se for false, pula para o próximo else if ou else.

int vida = 35;

if (vida <= 0)
{
    Debug.Log("Voce morreu!");
}
else if (vida < 30)
{
    Debug.Log("Cuidado! Vida baixa!");
}
else if (vida < 60)
{
    Debug.Log("Vida moderada.");
}
else
{
    Debug.Log("Vida cheia ou proxima!");
}
// Resultado: "Vida moderada." (porque 35 esta entre 30 e 60)
Passo a passo no Editor:
1. No Unity, crie um GameObject vazio (GameObject → Create Empty)
2. Clique com botao direito no GameObject → Create → C# Script
3. Nomeie o script como TesteCondicionais e abra no IDE
4. Cole o codigo acima dentro do metodo Start()
5. Volte ao Unity e arraste o script para o GameObject vazio
6. Clique em Play e abra o painel Console (Window → General → Console)
Saida esperada no Console:
Vida moderada.
Teste no Editor: Altere o valor de vida para 0, 15 e 80. Observe qual mensagem aparece no Console para cada valor.

3.2 — Operador Ternario

Uma forma compacta de if/else para situações simples. A sintaxe é: condicao ? valor_se_verdadeiro : valor_se_falso

int vida = 0;

// Se vida > 0, status = "Vivo". Senao, status = "Morto"
string status = (vida > 0) ? "Vivo" : "Morto";
Debug.Log(status); // "Morto"
Passo a passo no Editor:
1. No mesmo script TesteCondicionais, substitua o codigo do Start() por:
int vida = 0; string status = (vida > 0) ? "Vivo" : "Morto"; Debug.Log(status);
2. Clique em Play e veja o resultado
Saida esperada no Console:
Morto
Teste no Editor: Mude vida para 50 e execute novamente. O resultado deve mudar para Vivo.

3.3 — Switch

Útil quando você precisa testar multiplos valores para a mesma variável. É mais legível que uma sequência de else if quando voce compara muitos valores.

string arma = "Espada";

switch (arma)
{
    case "Espada":
        Debug.Log("Ataque corpo a corpo. Dano: 15");
        break;
    case "Arco":
        Debug.Log("Ataque a distancia. Dano: 10");
        break;
    case "Cajado":
        Debug.Log("Magia. Dano: 20");
        break;
    default:
        Debug.Log("Arma desconhecida!");
        break;
}
Passo a passo no Editor:
1. Substitua o codigo do Start() por este bloco com switch
2. Clique em Play e veja qual mensagem aparece
Saida esperada no Console:
Ataque corpo a corpo. Dano: 15
Teste no Editor: Mude arma para "Arco" e "Cajado". Depois teste com um valor que nao existe no switch, como "Lanca", para ver a mensagem do default.

3.4 — Exemplo Pratico em Unity

public class SistemaDeDificuldade : MonoBehaviour
{
    [SerializeField] private int nivelDificuldade = 2;

    void Start()
    {
        switch (nivelDificuldade)
        {
            case 1: // Facil
                Debug.Log("Vida do inimigo: 50 | Dano: 5");
                break;
            case 2: // Medio
                Debug.Log("Vida do inimigo: 100 | Dano: 10");
                break;
            case 3: // Dificil
                Debug.Log("Vida do inimigo: 200 | Dano: 25");
                break;
            default:
                Debug.Log("Modo personalizado!");
                break;
        }
    }
}
Dica do Professor: Prefira switch quando voce compara a mesma variavel com muitos valores diferentes. E mais legivel e ligeiramente mais performatico que uma sequencia gigante de else if.
Teste completo no Editor:
1. Crie um novo GameObject vazio e adicione o script SistemaDeDificuldade
2. No Inspector, mude o valor de Nivel Dificuldade para 1, 2 ou 3
3. Clique em Play e observe as mensagens diferentes no Console
4. Teste com um valor fora do switch (como 99) para ver o default
Atividade Pratica no Unity:
1. Crie um script SistemaDano.cs

4. Calcule e exiba: Debug.Log($"Dano final: {danoBase * multiplicador}")

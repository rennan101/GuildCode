7. Classes e Objetos — POO Basico

Módulo 1 — Fundamentos de C# para Unity

Programacao Orientada a Objetos (POO) e o paradigma do C#. Uma classe e um "molde" e um objeto e uma instancia desse molde. No Unity, todo Script e uma classe!

7.1 — Criando uma Classe

using UnityEngine;

public class Inimigo : MonoBehaviour
{
    // Campos (variaveis da classe)
    [Header("Configuracoes do Inimigo")]
    [SerializeField] private string nome = "Goblin";
    [SerializeField] private int vidaMaxima = 100;
    [SerializeField] private float velocidade = 3f;
    [SerializeField] private int dano = 10;

    // Campo privado (estado interno)
    private int vidaAtual;
    private bool estaVivo = true;

    // Propriedade — controle de acesso aos dados
    public int VidaAtual => vidaAtual;
    public bool EstaVivo => estaVivo;

    // METODO START — chamado quando o objeto nasce
    void Start()
    {
        vidaAtual = vidaMaxima;
        Debug.Log($"{nome} apareceu! Vida: {vidaAtual}");
    }

    // METODO — comportamento
    public void ReceberDano(int quantidade)
    {
        if (!estaVivo) return;

        vidaAtual -= quantidade;
        Debug.Log($"{nome} recebeu {quantidade} de dano! Vida: {vidaAtual}");

        if (vidaAtual <= 0)
        {
            Morrer();
        }
    }

    void Morrer()
    {
        estaVivo = false;
        Debug.Log($"{nome} foi derrotado!");
        Destroy(gameObject, 1f); // Destroi apos 1 segundo
    }
}
Passo a passo no Editor:
1. Crie um Cube na cena (GameObject → 3D Object → Cube)
2. Renomeie para "Goblin"
3. Clique com botao direito no Cube → Create C# Script → nomeie "Inimigo"
4. Cole o codigo acima no script
5. Arraste o script para o Goblin no Inspector
6. No Inspector, ajuste: Nome = "Goblin", Vida Maxima = 100, Dano = 10
7. Clique em Play
Saida esperada no Console:
Goblin apareceu! Vida: 100

7.2 — Construtor

// Classes comuns (nao-MonoBehaviour) podem ter construtores
public class Item
{
    public string nome;
    public int valor;

    // Construtor — chamado ao criar o objeto
    public Item(string nomeItem, int valorItem)
    {
        nome = nomeItem;
        valor = valorItem;
    }
}

// Usando:
Item espada = new Item("Espada de Fogo", 150);
Debug.Log($"{espada.nome} custa {espada.valor} moedas");
MonoBehaviour vs Classe Comum: No Unity, scripts que herdam de MonoBehaviour sao anexados a GameObjects e NAO podem usar construtores. Use Start() ou Awake() para inicializacao. Classes que NAO herdam de MonoBehaviour (como Item acima) podem usar construtores normalmente.

7.3 — Encapsulamento

public class Personagem : MonoBehaviour
{
    // private — so acessivel DENTRO da classe
    private int vida;

    // public — acessivel de QUALQUER lugar
    public string nome;

    // Propriedade com get/set controlado
    public int Vida
    {
        get => vida;
        set
        {
            if (value < 0) value = 0;        // Nunca negativo
            if (value > 100) value = 100;     // Nunca acima do maximo
            vida = value;
        }
    }
}

// Uso:
Personagem p = GetComponent<Personagem>();
p.Vida = -50; // Setter garante que sera 0
p.Vida = 200; // Setter garante que sera 100
Debug.Log(p.Vida); // 100
Dica do Professor: Use [SerializeField] private em vez de public para campos expostos no Inspector. Isso mantem os dados protegidos (encapsulamento) enquanto permite ajustes no Editor!

4. Loops — Repetição

Módulo 1 — Fundamentos de C# para Unity

Loops permitem repetir código varias vezes. São essenciais para percorrer listas, animar objetos, gerar inimigos em waves, etc.

4.1 — For Loop

Quando voce sabe quantas vezes quer repetir. O for tem tres partes: inicializacao; condicao; incremento

// Sintaxe: for (inicializacao; condicao; incremento)
for (int i = 0; i < 5; i++)
{
    Debug.Log($"Repeticao numero: {i}");
}
// Saida: 0, 1, 2, 3, 4
Passo a passo no Editor:
1. Crie um GameObject vazio e adicione um script TesteLoops
2. Cole o codigo acima dentro do Start()
3. Clique em Play e abra o Console
4. Observe: o numero comeca em 0 e vai ate 4 (nao 5!)
Saida esperada no Console:
Repeticao numero: 0
Repeticao numero: 1
Repeticao numero: 2
Repeticao numero: 3
Repeticao numero: 4
Teste no Editor: Mude i < 5 para i <= 5 e observe a diferenca. Agora o resultado vai ate 5!

4.2 — Gerando Inimigos com For

// Gerar 10 inimigos em posicoes diferentes
for (int i = 0; i < 10; i++)
{
    Vector3 posicao = new Vector3(i * 3f, 0, 0);
    Instantiate(inimigoPrefab, posicao, Quaternion.identity);
    Debug.Log($"Inimigo {i + 1} criado em {posicao}");
}
Passo a passo no Editor:
1. Crie um prefab de inimigo: crie um Cube, renomeie para "InimigoPrefab"
2. Arraste o Cube para a pasta Assets/Prefabs (o Unity cria o prefab)
3. Delete o Cube da cena
4. Crie um GameObject vazio, nomeie "Gerador"
5. Adicione um script GeradorInimigos e cole o codigo
6. No Inspector, arraste o prefab InimigoPrefab para o campo Inimigo Prefab
7. Clique em Play e veja os inimigos aparecerem
Saida esperada no Console:
Inimigo 1 criado em (0.0, 0.0, 0.0)
Inimigo 2 criado em (3.0, 0.0, 0.0)
Inimigo 3 criado em (6.0, 0.0, 0.0)
... ate Inimigo 10

4.3 — While Loop

Quando voce nao sabe quantas vezes vai repetir — repete enquanto a condicao for verdadeira:

int vida = 100;
int danoPorTick = 15;

while (vida > 0)
{
    vida -= danoPorTick;
    Debug.Log($"Recebeu {danoPorTick} de dano! Vida: {vida}");
}
Debug.Log("O jogador morreu!");
// Resultado: Vai drenar 15 por vez ate 0 ou menos
Passo a passo no Editor:
1. No mesmo script, adicione este codigo no Start()
2. Clique em Play e observe o dano sendo aplicado repetidamente
Saida esperada no Console:
Recebeu 15 de dano! Vida: 85
Recebeu 15 de dano! Vida: 70
Recebeu 15 de dano! Vida: 55
Recebeu 15 de dano! Vida: 40
Recebeu 15 de dano! Vida: 25
Recebeu 15 de dano! Vida: 10
Recebeu 15 de dano! Vida: -5
O jogador morreu!
Cuidado com loops infinitos! Se a condicao nunca se tornar false, o Unity trava. Sempre garanta que algo dentro do loop vai alterar a condicao. Se travar no Editor, use Ctrl+C no console ou force o fechamento do Unity.

4.4 — Do-While Loop

Executa pelo menos uma vez antes de verificar a condicao:

int tentativas = 0;
bool bauAberto = false;

do
{
    tentativas++;
    Debug.Log($"Tentativa {tentativas} de abrir o bau...");
}
while (tentativas < 3 && !bauAberto);
// Executa no minimo 1 vez, mesmo que bauAberto ja seja true

4.5 — Foreach Loop

Percorre cada elemento de uma colecao (array, lista):

string[] itens = {"Espada", "Escudo", "Pocao", "Arco"};

foreach (string item in itens)
{
    Debug.Log($"Item encontrado: {item}");
}
Passo a passo no Editor:
1. Cole este codigo no Start() de um script
2. Clique em Play e veja cada item sendo listado
Saida esperada no Console:
Item encontrado: Espada
Item encontrado: Escudo
Item encontrado: Pocao
Item encontrado: Arco

4.6 — Break e Continue

// break — sai do loop imediatamente
for (int i = 0; i < 100; i++)
{
    if (i == 5)
    {
        Debug.Log("Chegou em 5, parando!");
        break; // Sai do loop
    }
}

// continue — pula para a proxima iteracao
for (int i = 0; i < 10; i++)
{
    if (i % 2 == 0)
        continue; // Pula numeros pares
    Debug.Log($"Impar: {i}"); // Exibe: 1, 3, 5, 7, 9
}
Passo a passo no Editor:
1. Teste primeiro o break: cole e execute
2. Depois teste o continue: cole e execute
3. Observe as diferencas no Console
Saida do break: Chegou em 5, parando!
Saida do continue: Impar: 1, Impar: 3, Impar: 5, Impar: 7, Impar: 9
Dica do Professor: break para o loop completamente. continue pula apenas a iteracao atual e continua a proxima. Pense: break = "parar!", continue = "pular esta vez!"
Atividade Pratica no Unity:
1. Crie GeradorDeOndas.cs
2. Use for para criar 5 inimigos com Instantiate(), cada um 3 metros mais afastado no eixo X
3. Use while para simular dano continuo: de 10 de dano por tick ate a vida chegar a 0
4. Use foreach em uma string[] com nomes de 3 inimigos e exiba no Debug.Log
Saida esperada:
• for: 5 mensagens "Inimigo X criado em (Y, 0, 0)"
• while: Sequencia de dano ate "O inimigo morreu!"
• foreach: 3 mensagens "Inimigo encontrado: ..."

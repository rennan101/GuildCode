8. Heranca e Polimorfismo

Módulo 1 — Fundamentos de C# para Unity

Heranca permite criar uma nova classe baseada em outra existente. A classe filha herda todos os campos e metodos da classe pai, e pode adicionar ou modificar comportamentos.

8.1 — Heranca Basica

// Classe base (pai)
public class Entidade : MonoBehaviour
{
    [SerializeField] protected int vidaMaxima = 100;
    protected int vidaAtual;
    protected bool estaVivo = true;

    protected virtual void Start()
    {
        vidaAtual = vidaMaxima;
    }

    public virtual void ReceberDano(int quantidade)
    {
        if (!estaVivo) return;
        vidaAtual -= quantidade;
        Debug.Log($"{name} recebeu {quantidade} de dano! Vida: {vidaAtual}");
        if (vidaAtual <= 0) Morrer();
    }

    protected virtual void Morrer()
    {
        estaVivo = false;
        Debug.Log($"{name} morreu!");
        Destroy(gameObject, 1f);
    }
}

// Classe filha
public class Inimigo : Entidade
{
    [SerializeField] private int dano = 10;

    protected override void Start()
    {
        base.Start(); // Chama o Start da classe pai!
        Debug.Log($"{name} entrou na batalha com {vidaAtual} HP");
    }

    public override void ReceberDano(int quantidade)
    {
        base.ReceberDano(quantidade); // Logica do pai
        Debug.Log($"{name} esta furioso!"); // Comportamento extra
    }

    // Metodo NOVO, exclusivo do Inimigo
    public void Atacar(Transform alvo)
    {
        if (!estaVivo) return;
        Debug.Log($"{name} atacou {alvo.name} causando {dano} de dano!");
    }
}
Conceitos importantes:
• protected = acessivel pela classe pai E pelas filhas (nao por classes externas)
• virtual = metodo que pode ser override (sobrescrito) pela classe filha
• override = substitui o metodo da classe pai
• base.Start() = chama o metodo da classe pai antes de executar o proprio
Passo a passo no Editor:
1. Crie 3 Cubos na cena: "Goblin", "Orc", "Boss"
2. Crie o script Entidade.cs (classe base) e Inimigo.cs (classe filha)
3. Adicione o script Inimigo a cada Cube
4. No Inspector de cada Cube, ajuste vidaMaxima e dano diferentes
5. Clique em Play e veja as mensagens
Saida esperada no Console:
Goblin entrou na batalha com 100 HP
Orc entrou na batalha com 150 HP
Boss entrou na batalha com 500 HP

8.2 — Outra Classe Filha — Mesmo Pai, Comportamento Diferente

// Coletavel herda de Entidade mas se comporta diferente
public class Coletavel : Entidade
{
    [SerializeField] private int valorCurar = 25;

    public override void ReceberDano(int quantidade)
    {
        // Coletaveis "morrem" quando o jogador toca (colisao)
        vidaAtual = 0;
        Morrer();
        Debug.Log($"{name} foi coletado! Cura: {valorCurar}");
    }
}

8.3 — Polimorfismo

Uma mesma chamada pode gerar comportamentos diferentes dependendo do tipo real do objeto:

// Lista de todas as entidades
List<Entidade> entidades = new List<Entidade>();
entidades.Add(inimigo);   // Tipo real: Inimigo
entidades.Add(coletavel); // Tipo real: Coletavel

// Mesmo metodo, comportamento diferente!
foreach (Entidade ent in entidades)
{
    ent.ReceberDano(50); // Chama a versao CORRETA de cada classe
}
Conceito Chave: Em Unity, toda classe que herda de MonoBehaviour ja esta usando heranca — porque sua classe herda de MonoBehaviour que herda de Behaviour que herda de Component que herda de Object!
Atividade Pratica no Unity:
1. Crie a classe base Veiculo.cs (nao-MonoBehaviour) com: marca, velocidadeMax, metodo Dirigir()
2. Crie Carro : Veiculo com metodo Drift() adicional
3. Crie Moto : Veiculo com override de Dirigir() que exibe mensagem diferente
4. No Unity, crie um MonoBehaviour que instancie ambos e chame Dirigir() de cada um
Saida esperada no Console:
Fusca andando a 120 km/h!
Honda CBR andando a 180 km/h! (moto resistindo ao vento)
Fusca fazendo drift na curva!

DESAFIO DO MODULO 1 — Mini RPG em C#

Aplique tudo que voce aprendeu ate agora para criar um mini sistema de combate no Unity!

Requisitos:
1. Crie uma classe base Entidade (MonoBehaviour) com: string nome, int vidaMaxima, int danoBase
2. Crie Jogador : Entidade com metodo Atacar(Entidade alvo) e Curar(int quantidade)
3. Crie Inimigo : Entidade com metodo AtacarJogador(Jogador jogador)
4. Crie uma classe GerenciadorBatalha (MonoBehaviour) que:
   • Use um for loop para simular 10 rodadas de combate
   • Use if/else para verificar se algum lado morreu
   • Use Debug.Log para mostrar cada acao
5. No Start(), crie o jogador e 2 inimigos (use listas!)
6. Execute a batalha e exiba o resultado

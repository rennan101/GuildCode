6. Arrays e Listas

Módulo 1 — Fundamentos de C# para Unity

Arrays e Listas permitem armazenar multiplos valores do mesmo tipo em uma unica variavel. Essencial para inventarios, waves de inimigos, ranking, etc.

6.1 — Arrays — Tamanho Fixo

Um array e uma colecao de valores com tamanho definido na criacao. Os indices comecam em 0!

// Declarando um array (tamanho definido na criacao)
string[] nomesInimigos = new string[3];
nomesInimigos[0] = "Goblin";
nomesInimigos[1] = "Orc";
nomesInimigos[2] = "Troll";

// Ou de forma simplificada:
int[] vidaInimigos = { 50, 100, 200 };
float[] velocidades = { 3.5f, 2.0f, 4.5f };

// Acessando elementos (indices comecam em 0!)
string primeiro = nomesInimigos[0]; // "Goblin"
int vidaDoOrc = vidaInimigos[1];    // 100

// Modificando:
nomesInimigos[2] = "Dragao"; // Troll vira Dragao

// Tamanho do array:
int total = nomesInimigos.Length; // 3
Passo a passo no Editor:
1. Crie um GameObject vazio e adicione um script TesteArrays
2. Cole o codigo acima no Start()
3. Adicione: Debug.Log($"Primeiro inimigo: {primeiro}"); Debug.Log($"Vida do Orc: {vidaDoOrc}"); Debug.Log($"Total: {total}");
4. Clique em Play e veja os resultados
Saida esperada no Console:
Primeiro inimigo: Goblin
Vida do Orc: 100
Total: 3
IndexOutOfRangeException: Se tentar acessar array[3] em um array de tamanho 3, o Unity lança erro! Os indices vao de 0 a Length - 1 (0, 1, 2 neste caso).
Teste no Editor: Tente acessar nomesInimigos[3] e veja o erro no Console. Depois corrija para nomesInimigos[2].

6.2 — List<T> — Tamanho Dinamico

Arrays tem tamanho fixo. List<T> permite adicionar e remover elementos em tempo de execucao:

using System.Collections.Generic; // Necessario!

// Declarando uma lista
List<string> inventario = new List<string>();

// Adicionando itens
inventario.Add("Espada");
inventario.Add("Escudo");
inventario.Add("Pocao de Vida");
Debug.Log($"Itens: {inventario.Count}"); // 3

// Acessando
string primeiroItem = inventario[0]; // "Espada"

// Removendo
inventario.Remove("Pocao de Vida"); // Remove pelo valor
Debug.Log($"Itens restantes: {inventario.Count}"); // 2

// Verificar se contem
bool temEspada = inventario.Contains("Espada"); // true

// Limpar tudo
inventario.Clear(); // Lista vazia
Passo a passo no Editor:
1. No inicio do script, adicione: using System.Collections.Generic;
2. Cole o codigo da lista no Start()
3. Clique em Play e observe as mensagens
Saida esperada no Console:
Itens: 3
Itens restantes: 2

6.3 — Percorrendo Arrays e Listas

int[] vidaInimigos = { 50, 100, 200, 75 };

// Usando foreach
foreach (int vida in vidaInimigos)
{
    Debug.Log($"Inimigo com {vida} de vida");
}

// Usando for (quando precisa do indice)
for (int i = 0; i < vidaInimigos.Length; i++)
{
    Debug.Log($"Inimigo {i}: {vidaInimigos[i]} HP");
}
Passo a passo no Editor:
1. Cole o codigo acima no Start()
2. Clique em Play
3. Observe: foreach nao mostra o indice, for mostra!
Saida do foreach:
Inimigo com 50 de vida
Inimigo com 100 de vida
Inimigo com 200 de vida
Inimigo com 75 de vida

Saida do for:
Inimigo 0: 50 HP
Inimigo 1: 100 HP
Inimigo 2: 200 HP
Inimigo 3: 75 HP

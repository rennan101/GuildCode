# Assuntos — C# com Unity (Base do Procedural Training System / PTS)

Lista de assuntos que alimentam o **Procedural Training System (PTS)**. Cada assunto possui pré-requisitos, faixa de dificuldade e templates de atividade (enunciado, saída esperada e verificador). Derivado do `index.html` + tópicos avançados de Unity.

## Módulo 1 — Fundamentos de C#
1. Variáveis e Tipos de Dados — `int`, `float`, `string`, `bool`, `char`
2. Operadores e Expressões — aritméticos, relacionais, lógicos, compostos
3. Condicionais (if, else, switch) — tomada de decisão e operador ternário
4. Loops (for, while, foreach) — repetição, break/continue
5. Funções e Métodos — parâmetros, retorno, void
6. Arrays e Listas — arrays fixos e `List<T>` dinâmica
7. Classes e Objetos (OOP) — classes, construtores, propriedades, encapsulamento
8. Herança e Polimorfismo — override, classes abstratas, interfaces

## Módulo 2 — Fundamentos do Unity
9. GameObjects e Components — estrutura base, tags, layers
10. Transform — posição, rotação e escala
11. Ciclo de Vida — Awake, Start, Update, FixedUpdate, LateUpdate

## Módulo 3 — Input System Moderno
12. Input System Moderno — Keyboard.current, Mouse.current
13. Input Actions — mapeamentos reconfiguráveis (.inputactions)

## Módulo 4 — Matemática 3D
14. Sistemas de Coordenadas 3D
15. Vetores 3D — Vector3, normalização, produto escalar/cruzado
16. Planos 3D e Projeções — raycasting, projeção perspectiva/ortogonal

## Módulo 5 — Física 3D
17. Rigidbody e Física — linearVelocity, massa, Forcemodes
18. Colisões e Triggers — OnCollisionEnter, OnTriggerEnter

## Módulo 6 — Câmeras
19. Câmera 3ª Pessoa (Cinemachine)
20. Câmera 1ª Pessoa (FPS / Mouse Look)

## Módulo 7 — Mundo 3D
21. Geometrias 3D e Meshes
22. Terreno e Vegetação
23. Iluminação — Lightmapping, APV, Post-Processing

## Módulo 8 — Interface e Sistemas
24. Interface Gráfica (HUD/UI) — Canvas, TextMeshPro
25. Sistemas de Partículas — Particle System, VFX Graph
26. Efeitos Sonoros 3D — AudioSource, AudioListener
27. NavMesh e NPC — NavMeshAgent, patrulha
28. Shaders Básicos — Shader Graph, materiais PBR

## Módulo 9 — Avançado (Tópicos PTS)
29. Instantiate e Destroy — criação/remoção dinâmica de GameObjects
30. Object Pooling — reuso de objetos para evitar garbage collection
31. ScriptableObjects — dados configuráveis fora da cena
32. Save/Load com PlayerPrefs — persistência simples de dados
33. Save/Load com JSON — serialização de estruturas complexas
34. Coroutines e IEnumerator — operações assíncronas e WaitForSeconds
35. Delegates e Events — callbacks e eventos personalizados
36. Interfaces — contratos entre classes
37. Tratamento de Exceções (try/catch) — robustez do código
38. Otimização — Occlusion Culling, draw calls, batching e profiling

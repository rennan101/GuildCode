20. Camera 1ª Pessoa (FPS)

Módulo 6 — Câmeras

Uma camera de 1ª pessoa mostra o mundo pelos olhos do personagem. Usada em FPS, simuladores, e jogos de terror.

20.1 — Camera FPS com Mouse Look

using UnityEngine;
using UnityEngine.InputSystem;

public class CameraPrimeiraPessoa : MonoBehaviour
{
    [SerializeField] private float sensibilidadeX = 2f;
    [SerializeField] private float sensibilidadeY = 2f;
    [SerializeField] private float limitVertical = 80f;

    private float rotacaoX;

    void Start()
    {
        Cursor.lockState = CursorLockMode.Locked;
        Cursor.visible = false;
    }

    void Update()
    {
        Vector2 delta = Mouse.current.delta.ReadValue();

        float mouseX = delta.x * sensibilidadeX;
        float mouseY = delta.y * sensibilidadeY;

        // Rotacao vertical (olhar cima/baixo)
        rotacaoX -= mouseY;
        rotacaoX = Mathf.Clamp(rotacaoX, -limitVertical, limitVertical);

        // Rotacao horizontal (olhar esquerda/direita)
        transform.parent.Rotate(Vector3.up, mouseX);

        // Rotacao vertical so neste eixo
        transform.localRotation = Quaternion.Euler(rotacaoX, 0, 0);
    }
}
Passo a passo no Editor:
1. Crie um Capsule (Player) e posicione a Camera como filho em Y=0.8
2. Adicione o script CameraPrimeiraPessoa a Camera
3. No Inspector, ajuste sensibilidade
4. Clique em Play — cursor trava no centro
5. Mova o mouse — camera segue o olhar!
Resultado esperado:
• Camera olha na direcao do mouse
• Movimento vertical limitado a 80 graus
• Cursor invisivel e travado
Dica do Professor: Cursor.lockState = CursorLockMode.Locked trava o mouse no centro da tela. Essencial para FPS! Pressione ESC durante o jogo para testar o cursor.
Atividade Pratica no Unity:
1. Monte uma cena FPS basica: chao (Plane), 3 Cubos como alvos
2. Implemente camera FPS com mouse look
3. Implemente movimento WASD com Rigidbody
4. Implemente pulo com Espaco
5. Ao clicar, use Raycast para "atirar" — ao acertar Cube, destrua ele
Resultado esperado:
• Camera segue mouse suavemente
• Player se move com WASD e pula
• Ao clicar em Cube, ele desaparece e Console mostra "Acertou!"

DESAFIO DO MODULO 6 — Camera com Zoom

Crie um sistema de camera completo com zoom e transicao!

Requisitos:
1. Implemente camera 3ª pessoa que segue o Player
2. Ao rolar o scroll do mouse, aproximize/afaste a camera (zoom)
3. Implemente botao middle-click (scroll wheel) para resetar o zoom
4. Implemente transicao suave entre camera 3ª e 1ª pessoa ao pressionar V
5. A camera 1ª pessoa deve ter mouse look suave
Resultado esperado:
• Scroll up/down muda distancia da camera
• V alterna entre 1ª e 3ª pessoa com transicao suave
• Ambas as cameras funcionam com mouse look

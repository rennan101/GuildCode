21. Geometrias 3D e Meshes

Módulo 7 — Mundo 3D

Todos os objetos visuais no Unity sao feitos de Meshes — malhas 3D compostas de vertices, arestas e faces triangulares.

Passo a passo no Editor:
1. Menu: GameObject → 3D Object → selecione cada primitiva
2. Selecione um Cube → veja no Inspector: MeshFilter + MeshRenderer
3. No MeshFilter, veja "Mesh: Cube" — essa e a geometria
4. No MeshRenderer, veja "Element 0" — esse e o material

21.2 — Importando Modelos 3D

Formatos suportados:
• .fbx — padrao da industria (recomendado)
• .obj — formato simples, bom para modelos basicos
• .blend — arquivos Blender diretos (precisa do Blender instalado)

Onde encontrar modelos: Unity Asset Store, Sketchfab, TurboSquid, Mixamo (personagens com animacao)
Passo a passo — Importando modelo:
1. Baixe um modelo .fbx (ex: do Mixamo ou Unity Asset Store)
2. Arraste para a pasta Assets/Models
3. Selecione o modelo → Inspector → Model tab
4. Ajuste: Scale Factor, Mesh Compression, Read/Write
5. Crie um prefab arrastando o modelo para a cena

21.3 — Modificando Meshes via Script

using UnityEngine;

public class ModificarMesh : MonoBehaviour
{
    void Start()
    {
        MeshFilter mf = GetComponent<MeshFilter>();
        Mesh mesh = mf.mesh; // Cria copia do mesh

        // Acessar vertices
        Vector3[] vertices = mesh.vertices;
        Debug.Log($"Total de vertices: {vertices.Length}");

        // Modificar vertice 0
        vertices[0] += Vector3.up * 0.5f;
        mesh.vertices = vertices;

        // Recalcular normais e bounding box
        mesh.RecalculateNormals();
        mesh.RecalculateBounds();
    }
}
Atividade Pratica no Unity:
1. Importe um modelo 3D basico (pode ser do Asset Store gratuito)
2. Crie uma cena: chao (Plane) + 3 primitivas diferentes
3. Ajuste materiais (cor, metalico, rugosidade) em cada objeto
4. Implemente um script que modifique os vertices de um Cube (desenhe uma montanha!)
Resultado esperado:
• Cena com chao e 3 objetos de tipos diferentes
• Cada objeto com cor/material diferente
• Cube deformado com vertices modificados

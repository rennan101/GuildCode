27. NavMesh e NPC Autonomo

Módulo 8 — Interface e Sistemas

NavMesh permite que NPCs se movam autonomamente pelo cenario, desviando de obstaculos automaticamente.

27.1 — Configurando NavMesh

Passo a passo no Editor:
1. Instale NavMesh: Window → Package Manager → AI Navigation
2. Crie o cenario: Plane (chao) + Cubes (obstaculos)
3. Selecione o Plane → marca como "Static"
4. Menu: GameObject → AI → NavMesh Surface
5. No Inspector do NavMesh Surface, clique "Build"
6. Veja: areas navegaveis ficam azuis no Scene View!
7. Crie um NPC (Capsule) e adicione: Nav Mesh Agent

27.2 — NPC com NavMeshAgent

using UnityEngine;
using UnityEngine.AI;

public class NPCPatrulha : MonoBehaviour
{
    [SerializeField] private Transform[] pontosPatrulha;
    [SerializeField] private float tempoEspera = 2f;

    private NavMeshAgent agente;
    private int indicePontoAtual;
    private float timer;

    void Start()
    {
        agente = GetComponent<NavMeshAgent>();

        // Configurar agente
        agente.speed = 3.5f;       // Velocidade
        agente.stoppingDistance = 1f; // Distancia para parar

        // Ir para o primeiro ponto
        IrParaProximoPonto();
    }

    void Update()
    {
        // Verificar se chegou no ponto
        if (!agente.pathPending && agente.remainingDistance < agente.stoppingDistance)
        {
            timer += Time.deltaTime;

            if (timer >= tempoEspera)
            {
                IrParaProximoPonto();
                timer = 0f;
            }
        }
    }

    void IrParaProximoPonto()
    {
        if (pontosPatrulha.Length == 0) return;

        agente.SetDestination(pontosPatrulha[indicePontoAtual].position);
        Debug.Log($"Indo para ponto {indicePontoAtual}");

        indicePontoAtual = (indicePontoAtual + 1) % pontosPatrulha.Length;
    }
}
Passo a passo no Editor:
1. Crie 4 GameObjects vazios como pontos de patrulha
2. Crie um Capsule como NPC
3. Adicione NavMeshAgent ao NPC
4. Adicione o script NPCPatrulha
5. No Inspector, arraste os 4 pontos para o array "Pontos Patrulha"
6. Clique em Play — o NPC caminha entre os pontos!
Resultado esperado:
Indo para ponto 0
Indo para ponto 1
Indo para ponto 2
Indo para ponto 3
Indo para ponto 0 (repete)

27.3 — NPC perseguindo o Player

public class NPCPerseguicao : MonoBehaviour
{
    [SerializeField] private Transform player;
    [SerializeField] private float distanciaDeteccao = 15f;
    [SerializeField] private float distanciaAtaque = 2f;

    private NavMeshAgent agente;

    void Start()
    {
        agente = GetComponent<NavMeshAgent>();
    }

    void Update()
    {
        float dist = Vector3.Distance(transform.position, player.position);

        if (dist <= distanciaDeteccao)
        {
            // Perseguir o player
            agente.SetDestination(player.position);
            Debug.Log("Perseguindo player!");

            if (dist <= distanciaAtaque)
            {
                Debug.Log("Atacou o player!");
            }
        }
        else
        {
            // Voltar para patrulha
            agente.SetDestination(transform.position);
        }
    }
}
Atividade Pratica no Unity:
1. Monte uma cena com chao e obstaculos
2. Faca bake do NavMesh
3. Crie 2 NPCs: um patrulhando (4 pontos), outro perseguindo o player
4. O NPC perseguidor deve desviar de obstaculos automaticamente
5. Implemente "Game Over" quando o NPC perseguidor alcancar o player
Resultado esperado:
• NPC 1 caminha entre 4 pontos e espera em cada um
• NPC 2 fica parado ate o player se aproximar, entao persegue
• Ambos desviam de obstaculos
• "GAME OVER" ao ser alcancado

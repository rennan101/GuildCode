28. Shaders Basicos com Shader Graph

Módulo 8 — Interface e Sistemas

Shaders controlam como os objetos sao renderizados na tela. O Shader Graph permite criar shaders visuais sem escrever codigo HLSL.

28.1 — Shader Basico: Brilho Pulsante

Passo a passo no Editor:
1. Instale Shader Graph: Window → Package Manager → Shader Graph
2. Na pasta Assets, clique botao direito → Create → Shader Graph → URP → Lit Shader Graph
3. Nomeie "BrilhoPulsante"
4. Abra o Shader Graph (duplo clique)
5. Adicione nos:
   • Time node → Sine Node → Multiply Node (com cor base)
   • Resultado → Base Color do Master Stack
6. Clique "Save Asset" e aplique o material em um Cube

28.2 — Mudar Material via Codigo

using UnityEngine;

public class MaterialDinamico : MonoBehaviour
{
    [SerializeField] private float velocidadeCor = 2f;

    private Renderer rend;
    private Material mat;

    void Start()
    {
        rend = GetComponent<Renderer>();
        // Criar instancia do material (para nao afetar outros objetos)
        mat = new Material(rend.material);
        rend.material = mat;
    }

    void Update()
    {
        // Efeito de cor animada
        float t = (Mathf.Sin(Time.time * velocidadeCor) + 1f) / 2f;
        Color cor = Color.Lerp(Color.red, Color.blue, t);
        mat.color = cor;
    }
}

// Efeito de "taken damage" (pisca vermelho)
public class FlashDano : MonoBehaviour
{
    private Renderer rend;
    private Color corOriginal;
    private float tempoFlash;

    void Start()
    {
        rend = GetComponent<Renderer>();
        corOriginal = rend.material.color;
    }

    public void Flash()
    {
        rend.material.color = Color.red;
        tempoFlash = 0.2f;
    }

    void Update()
    {
        if (tempoFlash > 0)
        {
            tempoFlash -= Time.deltaTime;
            if (tempoFlash <= 0)
                rend.material.color = corOriginal;
        }
    }
}

Atividade Pratica no Unity:
1. Crie um Lit Shader Graph simples (cor + metalicidade ajustavel)
2. Crie um efeito Fresnel para um escudo brilhante
3. Use Flash() ao tomar dano — o objeto pisca vermelho
4. Crie um shader de agua simples com noise animado
Resultado esperado:
• Objeto muda de cor automaticamente (vermelho ↔ azul)
• Ao chamar Flash(), objeto pisca vermelho e volta a cor original
• Shader de agua com noise movendo horizontalmente

DESAFIO FINAL — Mini Jogo Completo

Integre tudo que voce aprendeu em um mini jogo!

Requisitos minimos:
1. Player: Capsule com movimento WASD, pulo (Espaco), camera 3ª pessoa
2. Cenario: Terreno com texturas + arvores + 1 Point Light
3. Moedas: 10 Spheres com Trigger que somem ao serem tocadas (+10 pontos)
4. Inimigo: NPC que persegue o player usando NavMesh
5. UI: Barra de vida (Slider), pontuacao (TMP), "GAME OVER" (TMP)
6. Audio: Som de moeda (2D), som de dano (2D), musica de fundo (2D)
7. Particulas: Explosao quando inimigo toca no player
8. Fisica: Player com Rigidbody + colisoes
Resultado esperado:
• Player se move e pula no terreno
• Moedas somem ao coletar (pontuacao sobe)
• Inimigo persegue e ao tocar causa dano
• Ao perder toda vida: GAME OVER com explosao
• Musica de fundo toca durante o jogo
• Som de moeda ao coletar, som de dano ao tomar dano

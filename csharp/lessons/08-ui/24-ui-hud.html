24. Interface Grafica (HUD/UI)

Módulo 8 — Interface e Sistemas

A UI (User Interface) e o painel de informacoes que o jogador ve na tela: barra de vida, pontuacao, mini-mapa, botoes de menu, etc.

24.1 — Elementos Basicos da UI

ElementoComponenteUso
TextoTextMeshPro (TMP)Pontuacao, vida, dialogo
ImagemImageIcones, barras de vida, fundos
BotaoButtonMenu, acoes
SliderSliderBarra de vida, volume
PainelPanelAgrupar elementos

24.2 — Criando UI Basica

Passo a passo no Editor:
1. Menu: GameObject → UI → Canvas (cria o Canvas automaticamente)
2. Dentro do Canvas, clique com botao direito → UI → Text - TextMeshPro
3. Renomeie para "TxtVida"
4. No Inspector, ajuste: Text = "Vida: 100", Font Size = 24
5. Crie mais um: UI → Slider
6. Renomeie para "BarraVida"
7. No Inspector, ajuste: Min Value = 0, Max Value = 100, Value = 100
8. Crie um botao: UI → Button - TextMeshPro

24.3 — Atualizando UI via Script

using UnityEngine;
using UnityEngine.UI;
using TMPro;

public class HUDJogador : MonoBehaviour
{
    [SerializeField] private Slider barraVida;
    [SerializeField] private TextMeshProUGUI txtVida;
    [SerializeField] private TextMeshProUGUI txtPontuacao;

    private int pontuacao = 0;
    private float vidaMax = 100f;
    private float vidaAtual = 100f;

    void Start()
    {
        AtualizarUI();
    }

    public void TomarDano(float quantidade)
    {
        vidaAtual = Mathf.Max(vidaAtual - quantidade, 0);
        AtualizarUI();
    }

    public void Curar(float quantidade)
    {
        vidaAtual = Mathf.Min(vidaAtual + quantidade, vidaMax);
        AtualizarUI();
    }

    public void AdicionarPontos(int pontos)
    {
        pontuacao += pontos;
        txtPontuacao.text = $"Pontos: {pontuacao}";
    }

    void AtualizarUI()
    {
        barraVida.value = vidaAtual;
        txtVida.text = $"Vida: {vidaAtual}/{vidaMax}";
    }
}
Passo a passo no Editor:
1. Selecione o Canvas
2. Adicione o script HUDJogador
3. No Inspector, arraste: BarraVida para Slider, TxtVida para Text
4. No Player, ao tomar dano, chame: FindObjectOfType<HUDJogador>().TomarDano(10f);
5. Clique em Play e veja a barra diminuir!
Atividade Pratica no Unity:
1. Crie um Canvas com: barra de vida (Slider), texto de vida (TMP), texto de pontuacao
2. Implemente: ao pressionar Espaco, perde 10 vida
3. Ao clicar, ganha 5 pontos
4. Quando vida chegar a 0, mostre "GAME OVER" no centro da tela
Resultado esperado:
• Barra de vida diminui ao pressionar Espaco
• Pontuacao aumenta ao clicar
• "GAME OVER" aparece quando vida = 0

1. Variáveis e Tipos de Dados em C#

Módulo 1 — Fundamentos de C# para Unity

Uma variável é como uma caixa rotulada onde guardamos dados. Cada caixa tem um nome (o rótulo), um tipo (que tipo de dado cabe nela) e um valor (o que está dentro).

Analogia do dia a dia: Pense numa estante de sapatos. Cada par de sapatos tem um número (o tipo), um local na estante (a variável) e é um sapato específico (o valor). Você não pode colocar um sapato número 42 num espaço marcado "número 38" — assim como não pode guardar texto numa variável de número inteiro.

Tipos Primitivos Essenciais

Em C#, existem vários "tamanhos de caixa" para diferentes tipos de dados:

TipoO que guardaExemplo Quando usar
intNúmero inteiro (sem decimal)int vida = 100;Vida, nível, moedas
floatNúmero decimalfloat velocidade = 5.5f;Velocidade, posição, tempo
doubleDecimal de alta precisãodouble pontuacao = 999.99;Cálculos financeiros
stringTexto (palavras, frases)string nome = "Jogador";Nomes, mensagens
boolVerdadeiro ou Falsobool estaVivo = true;Estado (vivo/morto, ativo/inativo)
charUm único caracterechar classe = 'G';Letra, símbolo único
Dica do Professor: No Unity, a maioria dos valores são float (posição, rotação, escala). Por isso, lembre sempre do f no final: 3.5f, não 3.5.

Teste no Editor — Criando seu primeiro script

  1. Abra o Unity e crie um novo projeto 3D (ou abra um existente)
  2. No painel Project, clique com botão direito em Assets → Create → C# Script
  3. Dê o nome JogadorInfo (o nome do arquivo DEVE ser igual ao nome da classe!)
  4. Dê duplo-clique no script para abrir no Visual Studio / VS Code
  5. Dentro de Start(), digite o código abaixo:
void Start()
{
    // Declarando e inicializando variáveis
    int vida = 100;
    float velocidade = 5.5f;
    string nomeDoJogador = "Herói";
    bool podeAtacar = true;
    char classe = 'G'; // Guerreiro

    // Exibir no Console do Unity
    Debug.Log("Nome: " + nomeDoJogador);
    Debug.Log("Vida: " + vida);
    Debug.Log("Velocidade: " + velocidade);
    Debug.Log("Pode atacar: " + podeAtacar);
    Debug.Log("Classe: " + classe);
}
  1. Volte ao Unity, arraste o script para um GameObject da cena (ex: um Cube)
  2. Clique em Play
  3. Abra o painel Console (Window → General → Console) para ver a saída
Saída esperada no Console: Nome: Herói Vida: 100 Velocidade: 5.5 Pode atacar: True Classe: G

Declarando Variáveis

Declarar uma variável é criar a caixa. Atribuir é colocar algo dentro dela. Você pode fazer as duas coisas ao mesmo tempo ou separadamente:

// Forma 1: Declarar E atribuir ao mesmo tempo
int vida = 100;
string nome = "Jogador";

// Forma 2: Declarar primeiro, atribuir depois
int moedas;          // A caixa existe, mas está vazia
moedas = 500;        // Agora tem um valor dentro

// ERRO: usar antes de atribuir
int pontuacao;
// Debug.Log(pontuacao); // ERRO! Variável não inicializada
Atividade — Teste no Editor:
No mesmo script JogadorInfo, dentro de Start(), adicione:
int moedas;
moedas = 500;
Debug.Log("Moedas: " + moedas);
Clique em Play e verifique o Console.
Saída esperada: Moedas: 500

Constantes — Valores que NUNCA mudam

Quando um valor nunca deve mudar durante o jogo, use a palavra-chave const. É como escrever a gravidade com caneta permanente — ninguém pode apagar:

// const = valor fixo, não pode ser alterado
const float GRAVIDADE = -9.81f;
const int MAXIMO_VIDA = 100;
const string NOME_JOGO = "Meu Jogo 3D";

// Isso causaria ERRO de compilação:
// GRAVIDADE = 0; // ERRO! Não pode mudar uma constante
Regra prática: Use const para valores que são verdadeiros UNIVERSAIS do seu jogo (gravidade, limite máximo de vida, nome do jogo). Use variáveis normais para valores que PODEM mudar (vida atual, posição, velocidade).

Conversão de Tipos (Casting)

Às vezes precisamos transformar um tipo em outro — como quando uma calculadora precisa converter "42" (texto) para 42 (número):

// Conversão IMPLÍCITA: o C# faz sozinho (int → float é seguro)
int pontuacaoInt = 100;
float pontuacaoFloat = pontuacaoInt; // 100.0 (correto)

// Conversão EXPLÍCITA: você precisa forçar (float → int perde decimais!)
float valorDecimal = 9.75f;
int valorInteiro = (int)valorDecimal; // 9 (o .75 foi cortado!)

// Convertendo texto para número
string textoNumero = "42";
int numeroConvertido = int.Parse(textoNumero); // "42" → 42

// Concatenação: juntando texto com número
int velox = 5;
string mensagem = "Velocidade: " + velox; // "Velocidade: 5"
Cuidado com (int): Ele trunca (corta) o decimal, NÃO arredonda. (int)9.75f = 9, não 10. Se quiser arredondar, use Mathf.RoundToInt(9.75f) = 10.

Interpolação de Strings — Texto com variáveis

O operador $ permite colocar variáveis dentro de texto usando chaves {}. É muito mais limpo que concatenar com +:

int vidaAtual = 75;
int vidaMaxima = 100;
string nome = "Herói";

// Forma antiga (verbosa e difícil de ler)
string msg1 = "Nome: " + nome + " | Vida: " + vidaAtual + "/" + vidaMaxima;

// Forma moderna com interpolação (limpa e legível)
string msg2 = $"Nome: {nome} | Vida: {vidaAtual}/{vidaMaxima}";

Debug.Log(msg2); // "Nome: Herói | Vida: 75/100"
Atividade — Interpolação no Editor:
Adicione ao seu Start():
int nivel = 5;
float xp = 1250.5f;
string msg = $"Level: {nivel} | XP: {xp}";
Debug.Log(msg);
Saída esperada: Level: 5 | XP: 1250.5
Resumo desta aula:
• int = números inteiros (100, -5, 0)
• float = números decimais com f (3.14f, 0.5f)
• string = texto entre aspas ("Olá")
• bool = verdadeiro ou falso (true / false)
• const = valor que nunca muda
• Debug.Log() = exibe mensagem no Console do Unity
• $"texto {variavel}" = interpolação de strings

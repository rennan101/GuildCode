2. Operadores e Expressões

Módulo 1 — Fundamentos de C# para Unity

Operadores são símbolos que realizam operações com variáveis e valores. Pense neles como os botões de uma calculadora — cada símbolo faz uma coisa diferente.

Operadores Aritméticos

São os operadores de matemática básica. Você já os conhece da escola:

int a = 10, b = 3;

int soma          = a + b;   // 13  → Soma: 10 + 3
int subtracao     = a - b;   // 7   → Subtração: 10 - 3
int multiplicacao = a * b;   // 30  → Multiplicação: 10 × 3
int divisao       = a / b;   // 3   → Divisão: 10 ÷ 3 (veja aviso!)
int resto         = a % b;   // 1   → Módulo: o que SOBRA após dividir
O que é o Módulo (%)? É o resto da divisão. Exemplo: 10 % 3 = 1 porque 10 ÷ 3 = 3 com resto 1. Muito usado para verificar se um número é par ou ímpar: numero % 2 == 0 significa "é par".
Cuidado com divisão inteira: 10 / 3 retorna 3, não 3.33! Isso porque os dois são int (inteiros). O decimal é "truncado" (cortado). Para obter o decimal: float resultado = 10f / 3;
Teste no Editor:
Crie um script Calculos.cs e adicione em Start():
int a = 10, b = 3;
Debug.Log($"Soma: {a + b}");           // 13
Debug.Log($"Subtração: {a - b}");      // 7
Debug.Log($"Multiplicação: {a * b}");  // 30
Debug.Log($"Divisão (int): {a / b}");  // 3 (truncado!)
Debug.Log($"Divisão (float): {10f / b}"); // 3.3333333
Debug.Log($"Módulo: {a % b}");         // 1 (resto)
Saída esperada: Soma: 13 Subtração: 7 Multiplicação: 30 Divisão (int): 3 Divisão (float): 3.3333333 Módulo: 1

Operadores de Atribuição Composta

São atalhos para operações matemáticas. Em vez de escrever vida = vida + 10, escreva vida += 10:

int vida = 100;

vida += 10;   // Mesmo que: vida = vida + 10  → 110 (curar)
vida -= 25;   // Mesmo que: vida = vida - 25  → 85  (dano)
vida *= 2;    // Mesmo que: vida = vida * 2   → 170 (power up)
vida /= 3;    // Mesmo que: vida = vida / 3   → 56  (dividir)
vida %= 7;    // Mesmo que: vida = vida % 7   → 0   (resto)
Teste no Editor:
No mesmo script, adicione:
int vida = 100;
Debug.Log($"Vida inicial: {vida}");

vida += 10;
Debug.Log($"Após curar (+10): {vida}");

vida -= 25;
Debug.Log($"Após dano (-25): {vida}");

vida *= 2;
Debug.Log($"Após power up (×2): {vida}");
Saída esperada: Vida inicial: 100 Após curar (+10): 110 Após dano (-25): 85 Após power up (×2): 170

Incremento e Decremento

Às vezes queremos apenas somar 1 ou subtrair 1 de uma variável. Em vez de escrever nivel = nivel + 1, usamos atalhos:

O que é "incremento"? É aumentar em 1.
O que é "decremento"? É diminuir em 1.

Existem duas formas, e a diferença está em quando o valor é atualizado:

int nivel = 5;

// PÓS-incremento: o ++ vem DEPOIS da variável
nivel++;    // Primeiro usa o valor atual (5), DEPOIS soma 1 → nivel vira 6
// É igual a: nivel = nivel + 1;

// PÓS-decremento: o -- vem DEPOIS da variável
nivel--;    // Primeiro usa o valor atual (6), DEPOIS subtrai 1 → nivel vira 5
// É igual a: nivel = nivel - 1;

// PRÉ-incremento: o ++ vem ANTES da variável
++nivel;    // Primeiro soma 1, DEPOIS usa o valor → nivel vira 6
// É igual a: nivel = nivel + 1;
Para iniciantes: Quando usa nivel++ ou ++nivel sozinhos (sem atribuir a outra variável), o resultado é exatamente o mesmo — a variável ganha +1. A diferença só importa em expressões como int x = nivel++;. Use qualquer uma que funcionará!
Teste no Editor:
int nivel = 5;
Debug.Log($"Nível inicial: {nivel}");

nivel++;
Debug.Log($"Após nivel++: {nivel}");

nivel--;
Debug.Log($"Após nivel--: {nivel}");

++nivel;
Debug.Log($"Após ++nivel: {nivel}");
Saída esperada: Nível inicial: 5 Após nivel++: 6 Após nivel--: 5 Após ++nivel: 6

Operadores Relacionais (Comparações)

Comparam dois valores e retornam apenas true (verdadeiro) ou false (falso):

OperadorSignificadoExemploResultado
==Igual a10 == 10true
!=Diferente de10 != 5true
>Maior que10 > 5true
<Menor que10 < 5false
>=Maior ou igual10 >= 10true
<=Menor ou igual10 <= 5false
Não confunda = com ==:
• = é atribuição: vida = 100; (guarda o valor)
• == é comparação: if (vida == 100) (verifica se são iguais)
Escrever if (vida = 0) é um erro muito comum!
Teste no Editor:
int vida = 50;
Debug.Log($"Vida == 50: {vida == 50}");   // True
Debug.Log($"Vida != 100: {vida != 100}"); // True
Debug.Log($"Vida > 30: {vida > 30}");     // True
Debug.Log($"Vida < 30: {vida < 30}");     // False
Debug.Log($"Vida >= 50: {vida >= 50}");   // True
Saída esperada: Vida == 50: True Vida != 100: True Vida > 30: True Vida < 30: False Vida >= 50: True

Operadores Lógicos

Permitem combinar várias condições em uma só expressão:

bool temEscudo = true;
int vida = 50;

// AND (&&) → "E" — ambas devem ser verdadeiras
bool podeReceberDano = !temEscudo && vida > 0;
// Resultado: false (tem escudo = true, então !true = false)

// OR (||) → "OU" — pelo menos uma deve ser verdadeira
bool podeCurar = vida < 30 || vida > 80;
// Resultado: false (50 < 30? Não. 50 > 80? Não.)

// NOT (!) → "NÃO" — inverte o valor
bool morreu = !true;  // false
Teste no Editor:
bool temEscudo = true;
int vida = 50;
Debug.Log($"Pode receber dano? {!temEscudo && vida > 0}");
Debug.Log($"Pode curar? {vida < 30 || vida > 80}");
Debug.Log($"Está morto? {!true}");
Saída esperada: Pode receber dano? False Pode curar? False Está morto? False

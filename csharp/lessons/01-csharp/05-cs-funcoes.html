5. Funcoes e Metodos

Módulo 1 — Fundamentos de C# para Unity

Uma funcao (ou metodo) e um bloco de codigo reutilizavel que realiza uma tarefa especifica. Em vez de repetir o mesmo codigo, voce cria uma funcao e a chama quantas vezes precisar.

5.1 — Anatomia de um Metodo

// Modificador  TipoRetorno  Nome  (Parametros)  { Corpo }
   public       void         Curar  (int quantidade)
{
    vida += quantidade;
    Debug.Log($"Curou {quantidade} de vida! Vida atual: {vida}");
}
Conceitos:
• public = modificador de acesso (quem pode chamar)
• void = tipo de retorno (o que retorna). void significa "nao retorna nada"
• Curar = nome do metodo
• int quantidade = parametro (dado que voce envia para o metodo)

5.2 — Metodos com Retorno

// Metodo que retorna um int
public int CalcularDano(int ataque, int defesa)
{
    int dano = ataque - defesa;
    if (dano < 0) dano = 0; // Dano minimo e 0
    return dano;
}

// Metodo que retorna um float
public float CalcularVelocidade(float baseSpeed, float multiplicador)
{
    return baseSpeed * multiplicador;
}

// Metodo que retorna bool
public bool EstaMorto(int vida)
{
    return vida <= 0;
}

// Usando:
int danoFinal = CalcularDano(30, 10);  // 20
float vel = CalcularVelocidade(5f, 1.5f); // 7.5
bool morreu = EstaMorto(0); // true
Passo a passo no Editor:
1. Crie um GameObject vazio e adicione um script TesteFuncoes
2. Dentro da classe (fora de qualquer metodo), cole os tres metodos acima
3. No Start(), chame cada metodo e exiba o resultado:
Debug.Log($"Dano: {CalcularDano(30, 10)}"); Debug.Log($"Velocidade: {CalcularVelocidade(5f, 1.5f)}"); Debug.Log($"Morto: {EstaMorto(0)}");
4. Clique em Play e veja os resultados
Saida esperada no Console:
Dano: 20
Velocidade: 7.5
Morto: True
Teste no Editor: Altere os valores dos parametros (por exemplo, CalcularDano(10, 20)) e observe que o resultado muda para Dano: 0 porque o dano negativo vira 0.

5.3 — Parametros com Valores Padrao

// Parametros opcionais — se nao passar valor, usa o padrao
public void Atacar(int dano = 10, string tipo = "Fisico")
{
    Debug.Log($"Atacou com {tipo} causando {dano} de dano!");
}

// Chamadas:
Atacar();           // "Atacou com Fisico causando 10 de dano!"
Atacar(25);         // "Atacou com Fisico causando 25 de dano!"
Atacar(30, "Magico"); // "Atacou com Magico causando 30 de dano!"
Passo a passo no Editor:
1. Cole o metodo Atacar dentro da classe
2. No Start(), adicione as tres chamadas (sem param, com 1 param, com 2 params)
3. Clique em Play e compare as tres saidas
Saida esperada no Console:
Atacou com Fisico causando 10 de dano!
Atacou com Fisico causando 25 de dano!
Atacou com Magico causando 30 de dano!

5.4 — Metodos void — Nao retornam nada

public void Morrer()
{
    Debug.Log("O personagem morreu!");
    // Nao tem return — apenas executa acoes
}

public void TomarDano(int quantidade)
{
    vida -= quantidade;
    if (vida <= 0)
    {
        Morrer(); // Chama outro metodo
    }
}

5.5 — Exemplo Completo em Unity

using UnityEngine;

public class Personagem : MonoBehaviour
{
    [SerializeField] private int vidaMaxima = 100;
    private int vidaAtual;

    void Start()
    {
        vidaAtual = vidaMaxima;
        Debug.Log($"Vida inicial: {vidaAtual}");
    }

    void Update()
    {
        // Teste rapido: pressione Espaco para tomar dano
        if (Input.GetKeyDown(KeyCode.Space))
        {
            TomarDano(15);
        }
    }

    void TomarDano(int quantidade)
    {
        if (quantidade <= 0) return; // Validacao
        vidaAtual -= quantidade;
        Debug.Log($"Tomou {quantidade} de dano! Vida: {vidaAtual}/{vidaMaxima}");

        if (EstarMorto())
        {
            Debug.Log("GAME OVER");
        }
    }

    void Curar(int quantidade)
    {
        vidaAtual = Mathf.Min(vidaAtual + quantidade, vidaMaxima);
        Debug.Log($"Curou {quantidade}! Vida: {vidaAtual}/{vidaMaxima}");
    }

    bool EstarMorto()
    {
        return vidaAtual <= 0;
    }

    float PorcentagemDeVida()
    {
        return (float)vidaAtual / vidaMaxima * 100f;
    }
}
Passo a passo no Editor:
1. Crie um GameObject vazio e adicione este script
2. Clique em Play
3. Pressione a tecla Espaco repetidamente
4. Observe a vida diminuindo no Console
5. Quando a vida chegar a 0, aparece "GAME OVER"
Saida esperada no Console (ao pressionar Espaco 7 vezes):
Vida inicial: 100
Tomou 15 de dano! Vida: 85/100
Tomou 15 de dano! Vida: 70/100
Tomou 15 de dano! Vida: 55/100
Tomou 15 de dano! Vida: 40/100
Tomou 15 de dano! Vida: 25/100
Tomou 15 de dano! Vida: 10/100
Tomou 15 de dano! Vida: -5/100
GAME OVER
Dica do Professor: Boas funcoes fazem uma coisa e so uma coisa. Em vez de criar uma funcao gigante que faz tudo, divida em funcoes menores: TomarDano(), Curar(), Morrer(). Isso facilita manutencao e depuracao!
Atividade Pratica no Unity:
1. Crie SistemaInventario.cs
2. Crie metodos: AdicionarItem(string item), RemoverItem(string item), TemItem(string item) → bool
3. Use um array ou lista para armazenar os itens
4. No Update(), teste com Input.GetKeyDown para adicionar/remover itens
5. Use Debug.Log para mostrar o estado do inventario
Saida esperada:
• Ao pressionar I: Adicionado: Item_0 | Total: 1
• Ao pressionar R: Removendo: Item_0
• Ao pressionar P: Lista do inventario completa

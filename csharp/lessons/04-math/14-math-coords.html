14. Sistemas de Coordenadas 3D

Módulo 4 — Matemática 3D

Para trabalhar em 3D, voce precisa entender como o Unity posiciona objetos no espaco. Tudo gira em torno do sistema de coordenadas.

14.1 — Eixos do Unity

Sistema de coordenadas mao esquerda:
• X = Esquerda/Direita (vermelho)
• Y = Cima/Baixo (verde)
• Z = Frente/Tras (azul)

Dica: olhe para os eixos coloridos no canto inferior esquerdo do Scene View! 
using UnityEngine;

public class Coordenadas3D : MonoBehaviour
{
    void Start()
    {
        // Posicao no mundo
        Vector3 posicao = transform.position;
        Debug.Log($"Posicao X: {posicao.x}"); // Esquerda/Direita
        Debug.Log($"Posicao Y: {posicao.y}"); // Cima/Baixo
        Debug.Log($"Posicao Z: {posicao.z}"); // Frente/Tras

        // Posicao local (relativa ao pai)
        Vector3 posLocal = transform.localPosition;

        // Diferenca entre position e localPosition:
        // position = coordenada GLOBAL na cena
        // localPosition = coordenada RELATIVA ao pai
    }
}
Passo a passo no Editor:
1. Crie um Cube e posicione em X=3, Y=5, Z=7
2. No Console, veja: Posicao: (3.0, 5.0, 7.0)
3. Crie um Cube filho (arraste sobre outro Cube no Hierarchy)
4. O filho tem localPosition diferente de position

14.2 — Mundo Local vs Mundo Global

void Start()
{
    // TransformDirection: converte direcao local para global
    Vector3 frenteLocal = transform.TransformDirection(Vector3.forward);
    Debug.Log($"Frente local (global): {frenteLocal}");

    // InverseTransformDirection: converte global para local
    Vector3 dirGlobal = Vector3.right;
    Vector3 dirLocal = transform.InverseTransformDirection(dirGlobal);
    Debug.Log($"Direita global (local): {dirLocal}");
}
Atividade Pratica no Unity:
1. Crie 3 Cubos em posicoes diferentes
2. Faca um Cube filho de outro
3. Compare transform.position e transform.localPosition de cada um
4. Rotacione o pai e observe como TransformDirection muda
Saida esperada:
Filho position: (5.0, 0.0, 3.0) (global)
Filho localPosition: (2.0, 0.0, 0.0) (relativo ao pai)

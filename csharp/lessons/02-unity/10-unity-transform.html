10. Transform — Posicao, Rotacao e Escala

Módulo 2 — Fundamentos do Unity

O Transform e o componente mais importante do Unity — todo GameObject tem um. Ele define a posicao, rotacao e escala do objeto no espaco 3D.

10.1 — Acessando o Transform

using UnityEngine;

public class ExplorarTransform : MonoBehaviour
{
    void Start()
    {
        // Posicao atual (coordenadas X, Y, Z)
        Vector3 pos = transform.position;
        Debug.Log($"Posicao: {pos}");
        // Exemplo: Posicao: (1.0, 2.0, 3.0)

        // Rotacao atual
        Quaternion rot = transform.rotation;
        Debug.Log($"Rotacao: {rot}");

        // Escala atual
        Vector3 esc = transform.localScale;
        Debug.Log($"Escala: {esc}");
    }
}
Passo a passo no Editor:
1. Crie um Cube na cena
2. No Inspector, posicione em X=1, Y=2, Z=3
3. Adicione o script ExplorarTransform
4. Clique em Play e veja as coordenadas no Console
Saida esperada no Console:
Posicao: (1.0, 2.0, 3.0)
Rotacao: (0.0, 0.0, 0.0, 1.0)
Escala: (1.0, 1.0, 1.0)

10.2 — Movendo Objetos

public class MovimentoBasico : MonoBehaviour
{
    [SerializeField] private float velocidade = 5f;

    void Update()
    {
        // Movimento relativo ao proprio eixo do objeto
        // (frente = Z+, tras = Z-, esquerda = X-, direita = X+)
        if (Input.GetKey(KeyCode.W))
            transform.Translate(Vector3.forward * velocidade * Time.deltaTime);
        if (Input.GetKey(KeyCode.S))
            transform.Translate(Vector3.back * velocidade * Time.deltaTime);
        if (Input.GetKey(KeyCode.A))
            transform.Translate(Vector3.left * velocidade * Time.deltaTime);
        if (Input.GetKey(KeyCode.D))
            transform.Translate(Vector3.right * velocidade * Time.deltaTime);
    }
}
O que e Time.deltaTime? E o tempo que passou desde o ultimo frame. Sem ele, o objeto se moveria mais rapido em computadores potentes e mais lento em fracos. Com Time.deltaTime, o movimento e consistente em qualquer maquina!
Passo a passo no Editor:
1. Crie um Cube e adicione o script MovimentoBasico
2. Clique em Play
3. Use W, A, S, D para mover o Cube
4. Observe: o Cube se move no seu proprio eixo (frente e sempre "pra frente")

10.3 — Rotacionando Objetos

public class RotacaoBasica : MonoBehaviour
{
    [SerializeField] private float velocidadeRotacao = 100f;

    void Update()
    {
        // Rotacao com Euler angles (graus)
        float mouseX = Input.GetAxis("Mouse X") * velocidadeRotacao * Time.deltaTime;
        transform.Rotate(Vector3.up, mouseX);

        // Rotacao direta com Quaternion
        // transform.rotation = Quaternion.Euler(45, 0, 0); // Inclina 45 graus
    }
}
Passo a passo no Editor:
1. Adicione o script RotacaoBasica ao Cube
2. Clique em Play
3. Mova o mouse para a esquerda/direita
4. O Cube rotaciona horizontalmente

10.4 — Mudando a Escala

public class EscalaDinamica : MonoBehaviour
{
    void Update()
    {
        // Tecla E: aumenta
        if (Input.GetKeyDown(KeyCode.E))
        {
            transform.localScale += Vector3.one * 0.1f;
            Debug.Log($"Escala: {transform.localScale}");
        }
        // Tecla Q: diminui
        if (Input.GetKeyDown(KeyCode.Q))
        {
            transform.localScale -= Vector3.one * 0.1f;
            Debug.Log($"Escala: {transform.localScale}");
        }
        // Tecla R: reseta
        if (Input.GetKeyDown(KeyCode.R))
        {
            transform.localScale = Vector3.one;
            Debug.Log("Escala resetada!");
        }
    }
}
Passo a passo no Editor:
1. Adicione o script EscalaDinamica ao Cube
2. Clique em Play
3. Pressione E varias vezes → o Cube cresce
4. Pressione Q → o Cube diminui
5. Pressione R → volta ao tamanho normal
Saida esperada no Console (ao pressionar E 3 vezes):
Escala: (1.1, 1.1, 1.1)
Escala: (1.2, 1.2, 1.2)
Escala: (1.3, 1.3, 1.3)
Dica do Professor: transform.Translate() move no espaco LOCAL do objeto. transform.position += move no espaco GLOBAL da cena. Para movimentar um player, prefira Translate().
Atividade Pratica no Unity:

2. Crie uma funcao Teleportar(Vector3 novaPosicao) que muda a posicao instantaneamente
3. Ao pressionar T, teleporte o Cube para (10, 5, 10)
4. Observe a diferenca entre mover e teletransportar
Saida esperada ao pressionar T:
Teleportado para: (10.0, 5.0, 10.0)

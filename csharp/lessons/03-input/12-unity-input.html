12. Input System Moderno (Unity 6.5)

Módulo 3 — Input System

O Unity 6.5 usa o Input System Package como padrao. O sistema antigo (Input.GetKey()) ainda funciona, mas o novo e mais poderoso, suporta multiplos controles e e mais flexivel.

12.1 — Ativacao

Configuracao: Va em Edit → Project Settings → Player → Active Input Handling e selecione "Input System Package (New)" ou "Both". No Unity 6.5, o padrao ja e o novo sistema.
Passo a passo — Ativar o Input System:
1. No Unity, va em Edit → Project Settings
2. Clique em "Player" no menu lateral
3. Role para baixo ate "Active Input Handling"
4. Selecione "Input System Package (New)" ou "Both"
5. O Unity pode pedir para reiniciar — aceite

12.2 — Forma 1: Keyboard.current (Mais Simples)

using UnityEngine;
using UnityEngine.InputSystem; // Namespace necessario!

public class InputSimples : MonoBehaviour
{
    void Update()
    {
        // Verificar se uma tecla esta pressionada (segurando)
        if (Keyboard.current[Key.W].isPressed)
        {
            transform.Translate(Vector3.forward * 5f * Time.deltaTime);
        }
        if (Keyboard.current[Key.S].isPressed)
        {
            transform.Translate(Vector3.back * 5f * Time.deltaTime);
        }
        if (Keyboard.current[Key.A].isPressed)
        {
            transform.Translate(Vector3.left * 5f * Time.deltaTime);
        }
        if (Keyboard.current[Key.D].isPressed)
        {
            transform.Translate(Vector3.right * 5f * Time.deltaTime);
        }

        // Tecla pressionada uma vez (down) — para acoes discretas
        if (Keyboard.current[Key.Space].wasPressedThisFrame)
        {
            Debug.Log("Espaco pressionado!");
        }

        // Tecla solta
        if (Keyboard.current[Key.Space].wasReleasedThisFrame)
        {
            Debug.Log("Espaco solto!");
        }

        // Shift esquerdo
        if (Keyboard.current.leftShiftKey.isPressed)
        {
            Debug.Log("Correndo!");
        }
    }
}
Passo a passo no Editor:
1. Crie um Capsule nomeado "Player"
2. Adicione um script InputSimples ao Player
3. No top do script, adicione: using UnityEngine.InputSystem;
4. Clique em Play
5. Use W, A, S, D para mover e Espaco para testar
Saida esperada (ao pressionar Espaco):
Espaco pressionado!
Espaco solto!

12.3 — Forma 2: Input Actions (Mais Organizada)

using UnityEngine;
using UnityEngine.InputSystem;

public class InputActionsExemplo : MonoBehaviour
{
    private Vector2 movimentoInput;
    private bool pulando;

    // Chamado pelo Input System automaticamente
    public void OnMove(InputAction.CallbackContext context)
    {
        movimentoInput = context.ReadValue<Vector2>();
        Debug.Log($"Movimento: {movimentoInput}");
    }

    public void OnJump(InputAction.CallbackContext context)
    {
        if (context.performed) // Quando pressionou
        {
            pulando = true;
            Debug.Log("Pulou!");
        }
        if (context.canceled) // Quando soltou
        {
            pulando = false;
        }
    }

    void Update()
    {
        if (pulando)
        {
            transform.Translate(Vector3.up * 10f * Time.deltaTime);
        }
    }
}
Passo a passo — Criando Input Actions:
1. No Project, clique com botao direito → Create → Input Actions
2. Nomeie "PlayerInput" e abra
3. Crie um Action Map "Player"
4. Crie actions: "Move" (Value, Vector2), "Jump" (Button)
5. Para "Move": associe W/A/S/D como Wasd
6. Para "Jump": associe Space
7. Selecione o Player no Hierarchy
8. Adicione componente "Player Input"
9. Arraste o asset PlayerInput para o campo "Actions"
10. Em "Behavior", selecione "Invoke Unity Events"

12.4 — Mouse Input

using UnityEngine;
using UnityEngine.InputSystem;

public class MouseLook : MonoBehaviour
{
    [SerializeField] private float sensibilidade = 2f;
    private float rotacaoX;

    void Update()
    {
        // Delta de movimento do mouse (movimento desde o ultimo frame)
        Vector2 deltaMouse = Mouse.current.delta.ReadValue();

        float mouseX = deltaMouse.x * sensibilidade;
        float mouseY = deltaMouse.y * sensibilidade;

        rotacaoX -= mouseY; // Invertido para sensacao natural
        rotacaoX = Mathf.Clamp(rotacaoX, -90f, 90f);

        transform.Rotate(Vector3.up, mouseX);
        transform.localRotation = Quaternion.Euler(rotacaoX, 0, 0);

        // Botoes do mouse
        if (Mouse.current.leftButton.wasPressedThisFrame)
        {
            Debug.Log("Clique esquerdo!");
        }
        if (Mouse.current.rightButton.wasPressedThisFrame)
        {
            Debug.Log("Clique direito!");
        }

        // Scroll do mouse
        float scroll = Mouse.current.scroll.ReadValue().y;
        if (scroll != 0)
        {
            Debug.Log($"Scroll: {scroll}");
        }
    }
}
Passo a passo no Editor:
1. Adicione o script MouseLook a um objeto (ex: Camera)
2. Clique em Play
3. Mova o mouse → o objeto rotaciona
4. Clique esquerdo/direito e veja no Console
5. Role o scroll e veja o valor
Saida esperada (ao clicar e rolar):
Clique esquerdo!
Clique direito!
Scroll: 120 (para cima) ou Scroll: -120 (para baixo)

12.5 — Comparacao: Sistema Antigo vs Novo

Antigo (Legado)Novo (Input System)
Input.GetKey(KeyCode.W)Keyboard.current[Key.W].isPressed
Input.GetKeyDown(KeyCode.Space)Keyboard.current[Key.Space].wasPressedThisFrame
Input.GetAxis("Horizontal")moveAction.ReadValue<float>()
Input.GetMouseButton(0)Mouse.current.leftButton.isPressed
Input.mousePositionMouse.current.position.ReadValue()
Dica do Professor: Para projetos grandes, sempre use Input Actions em vez de Keyboard.current direto. Isso permite ao jogador redefinir teclas (remapping) sem alterar o codigo!
Atividade Pratica no Unity:
1. Crie um script que use Keyboard.current[Key.W] para mover um Cube
2. Use Keyboard.current[Key.Space].wasPressedThisFrame para fazer o Cube "pular" (mover para cima)
3. Use Mouse.current.delta.ReadValue() para rotacionar o Cube com o mouse
4. Experimente: segure W + clique esquerdo e observe as duas acoes ao mesmo tempo
Saida esperada:
• Ao pressionar Espaco: Espaco pressionado!
• Ao clicar: Clique esquerdo!
• Ao mover mouse: Mouse delta: (X, Y)

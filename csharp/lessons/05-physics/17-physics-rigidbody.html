17. Rigidbody e Fisica 3D

Módulo 5 — Física 3D

O Rigidbody e o componente que permite que um GameObject reaja a fisica: gravidade, colisoes, forcas. O Unity 6.5 usa PhysX e introduziu a nova API linearVelocity.

17.1 — Configuracao Basica do Rigidbody

using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class ConfiguracaoFisica : MonoBehaviour
{
    private Rigidbody rb;

    void Start()
    {
        rb = GetComponent<Rigidbody>();

        // Configuracoes fisicas
        rb.mass = 2f;              // Massa (kg) — afeta colisoes
        rb.linearDamping = 0.5f;   // Arrasto linear (frenagem)
        rb.angularDamping = 0.5f;  // Arrasto angular (rotacao)
        rb.useGravity = true;      // Gravidade ativada
        rb.isKinematic = false;    // false = afetado pela fisica

        // Congelar rotacao para nao tombbar
        rb.constraints = RigidbodyConstraints.FreezeRotationX
                       | RigidbodyConstraints.FreezeRotationZ;
    }
}
Passo a passo no Editor:
1. Crie um Sphere (GameObject → 3D Object → Sphere)
2. Adicione componente Rigidbody (Component → Physics → Rigidbody)
3. No Inspector, veja: Mass, Drag, Angular Drag, Use Gravity, Is Kinematic
4. Clique em Play — a esfera cai por causa da gravidade!

17.2 — linearVelocity — A Nova Sintaxe do Unity 6

// MUDANCA IMPORTANTE no Unity 6:
// ANTES: rb.velocity = new Vector3(5, 0, 0);
// AGORA: rb.linearVelocity = new Vector3(5, 0, 0);

// Movimento direto (velocidade constante)
void FixedUpdate()
{
    // Preservar a velocidade Y (gravidade/pulo)
    rb.linearVelocity = new Vector3(
        movimentoHorizontal * velocidade,
        rb.linearVelocity.y, // Mantem gravidade
        movimentoVertical * velocidade
    );
}

// Zerar velocidade horizontal (parar instantaneamente)
void Parar()
{
    rb.linearVelocity = new Vector3(0, rb.linearVelocity.y, 0);
}
Regra de Ouro: NUNCA use transform.position para mover um objeto com Rigidbody! Use sempre rb.linearVelocity, AddForce ou rb.MovePosition(). Mover via Transform ignora a fisica e causa bugs.

17.3 — Forcas com AddForce

// ForceMode define COMO a fuerza e aplicada:

// ForceMode.Force — continuo, afetado pela massa
rb.AddForce(Vector3.forward * 100f, ForceMode.Force);

// ForceMode.Impulse — instantaneo, afetado pela massa (bom para tiros)
rb.AddForce(Vector3.up * 15f, ForceMode.Impulse);

// ForceMode.VelocityChange — instantaneo, IGNORA massa (movimento direto)
rb.AddForce(Vector3.forward * 10f, ForceMode.VelocityChange);

// ForceMode.Acceleration — continuo, IGNORA massa
Passo a passo no Editor:
1. Crie um Sphere com Rigidbody
2. Adicione um script que aplique AddForce(Vector3.up * 10f, ForceMode.Impulse) ao pressionar Espaco
3. Clique em Play e pressione Espaco
4. A esfera "pula" para cima!
Saida esperada:
• Ao pressionar Espaco: esfera salta para cima e cai de volta pela gravidade

17.4 — Exemplo Completo: Personagem 3D

using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody))]
public class PlayerFisica3D : MonoBehaviour
{
    [Header("Movimento")]
    [SerializeField] private float velocidade = 10f;
    [SerializeField] private float forcaPulo = 15f;

    [Header("Ground Check")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float raioCheck = 0.3f;
    [SerializeField] private LayerMask chaoMask;

    private Rigidbody rb;
    private Vector2 inputMovimento;
    private bool pulando;
    private bool noChao;

    void Start()
    {
        rb = GetComponent<Rigidbody>();
        rb.freezeRotation = true;
        rb.interpolation = RigidbodyInterpolation.Interpolate;
    }

    public void OnMove(InputAction.CallbackContext context)
    {
        inputMovimento = context.ReadValue<Vector2>();
    }

    public void OnJump(InputAction.CallbackContext context)
    {
        if (context.performed && noChao)
        {
            rb.AddForce(Vector3.up * forcaPulo, ForceMode.Impulse);
        }
    }

    void FixedUpdate()
    {
        noChao = Physics.CheckSphere(groundCheck.position, raioCheck, chaoMask);

        Vector3 move = new Vector3(inputMovimento.x, 0, inputMovimento.y);
        rb.linearVelocity = new Vector3(
            move.x * velocidade,
            rb.linearVelocity.y,
            move.z * velocidade
        );
    }
}

Dynamicfalsetrue/falseAfetado por fisica, forcas e colisoes
KinematictruefalseMovido por codigo, colide mas NAO e afetado
Static——Sem Rigidbody = estatico, so colide
Atividade Pratica no Unity:
1. Crie um Sphere com Rigidbody e teste AddForce(Vector3.up, ForceMode.Impulse) ao pressionar Espaco
2. Compare ForceMode.Force vs ForceMode.Impulse — mude a massa e observe a diferenca
3. Implemente movimento WASD usando rb.linearVelocity
4. Adicione um ground check com Physics.CheckSphere para limitar o pulo ao chao
Saida esperada:
• Ao pressionar Espaco: esfera pulaa para cima
• Com massa 1: pulo alto. Com massa 10: pulo baixo
• WASD move o objeto mantendo gravidade
